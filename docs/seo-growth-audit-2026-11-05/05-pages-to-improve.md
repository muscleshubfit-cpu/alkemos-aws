## الترتيب التنفيذي الإجمالي (يقابله ملف 07)

1. **أ (قياس فقط)** ← المرحلة 0/1.
2. **ب (النطاق العربي دفعة 1 + مقارنات أولى + قوائم)** ← المرحلة 1-2.
3. **ج (ذيل التمارين + كارديو)** ← المرحلة 3.
4. **د (مرافقات التحويل)** ← مستمر بالتوازي.
5. **هـ (فني صغير + قرارات معلقة)** ← عند استحقاقها فقط (D-2/D-4).
