> **صفة الوثيقة:** سجل تنفيذ حيّ داخل مجلد التقرير الحاكم نفسه (بلا مشروع توثيق مكرر — بأمر المالك). كل دفعة توثق: ما فُحص وما عُدّل · الملفات المتأثرة · سبب كل تعديل · نتائج الاختبارات · القياسات قبل/بعد عند توفرها · المؤجلات وقرارات المالك المطلوبة.
> **ترتيب الأولويات الملزم (معاد ترتيبه بأمر الدفعة 8):** جودة المحتوى الموجود (تصحيح التلوث التحريري والأخطاء) → الصفحات الخدمية المدفوعة وقيمة الاشتراك → AR/EN → الروابط الداخلية → الفهرسة → GEO → ذيل التمارين الموجود — **صفر صفحات جديدة**.
> **قانون الدفعات:** كل دفعة = فريم مستقل = كوميت واحد ببوابته الكاملة (tsc · eslint · vitest · build · الحرس · بوابات التوثيق) + كاناري يثبّت كل نص جديد.
