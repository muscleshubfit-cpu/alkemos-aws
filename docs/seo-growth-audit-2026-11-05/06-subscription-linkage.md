# 06 — ربط النمو العضوي بالاشتراكات (المحور السادس: EVO Free / EVO Pro / Online Coaching)

> **قاعدة أمر المالك:** «افحص مدى قدرة صفحات الموقع على تحويل الزائر إلى مستخدم مهتم بالاشتراك… دون إفساد تجربة المستخدم أو تحويل المحتوى إلى إعلانات». و**حد الصدق:** لا توجد بيانات تحويل منسوبة للزيارات العضوية قبل الآن (لا أحداث قمع مخصصة بالجلسات العضوية) — كل ما يلي خريطة وخطة قياس، لا أرقام تحويل مزعومة.

## 3. قواعد التكامل (كما تفرضها هوية Alkemos وأمر المالك) [توصية]
1. CTA واحد سياقي كحد أقصى لكل صفحة محتوى (بلا بانرات داخل النص) — بأسلوب «الترقية تقدّم» المعتمد بدراسة 413 (لا ضغط «الآن»، لا مبالغة).
2. القيمة قبل الطلب: كل CTA يذكر ما يأخذه المستخدم مجانًا تحديدًا (رقم أرقام: توليدان مجانًا).
3. لا سكيما إضافية للـCTA — العرض التجاري يبقى على أسطح العضويات (OfferCatalog قائم) والمحتوى يبقى معلوماتيًا نظيفًا (صيانة YMYL).
4. الشفافية الرقمية: كل رقم بالـCTA من memberships.ts (القانون المعمول به — تدقيق 416 ‏64/64).

## 4. قياس التحويل العضوي (المطلوب تأسيسه — أغلبها بلا كود) [توصية]
- **GA4:** تعريف Key Events للقمع (بدء توليد EVO مجاني ← إنشاء حساب ← بدء نسخة تجريبية/دفع) + قناة AI Assistant + تقرير «الوصول حسب القناة العضوية» (القناة موجودة؛ الأحداث تعريف Admin).
- **GSC→GA4 ربط الموضوع:** صفحات الهبوط العضوية × الأحداث (مقاس لاحقًا بقمع داخلي بلا كشف PII).
- **مؤشرات القيادة المقترحة:** (1) نسبة جلسات الأدوات التي تبدأ توليد EVO، (2) زيارات عضوية → تسجيل، (3) تسجيل مجاني → مدفوع (مع الوقت)، (4) نصيب مصر (السوق المنقرة الوحيد) بعد EGP.
- فصل واضح: «قياس أثر 413/414/416» (نافذة 4 أسابيع الجارية) ≠ «قياس قمع pSEO» (يبدأ مع الدفعة الأولى).

## 5. خلاصة المحور
- أسطح التحويل **جاهزة ومحسّنة** [قياس/موثق]؛ الناقص الحقيقي: (1) حجم الزيارات العضوية نفسه (يحله ملف 03)، (2) جسور سياقية طبيعية من صفحات البيانات الجديدة، (3) تعريف أحداث القمع بالـGA4 لأجل النسبة لا الادعاء.
