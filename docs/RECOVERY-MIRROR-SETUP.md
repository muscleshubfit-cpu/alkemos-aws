# RECOVERY-MIRROR-SETUP.md — دليل إعداد الـ Mirror الخارجي (P0-1)

> **الغرض:** الخطوات لمرة واحدة يقوم بها **المالك فقط** لتشغيل المرآة الخارجية المجهزة مسبقًا (`scripts/external-mirror/mirror.sh` + `.github/workflows/external-mirror.yml`) — لكسر العائق B2 (حساب GitHub واحد يحمل الكود + النسخ الخاصة + الأسرار + الأتمتة = نقطة فشل شاملة، مقيسة في تقرير التدقيق §9-B2).
> **حالة الجهوزية:** كل شيء مرفوع وجاهز — **لا يُنسخ أي شيء قبل إكمال هذه الخطوات** (سير العمل ساكن بتصميمه ويفشل بصوت عالٍ برسالة الإعداد المحددة حتى ذلك الحين).
> **تحديث الحالة (2026-10-04 — GD-3/GD-4 من `docs/BACKUP-STRATEGY-2026-10-03.md`): هذا الدليل أصبح «خطة بديلة خاملة»** — المسار الأساسي المعتمد والمنفَّذ للطبقة الخارجية هو **Google Drive المشفَّر** (`offsite-gdrive-upload.yml` أسبوعيًا/شهريًا + دريل الاستعادة الربعي `offsite-restore-drill.yml` — الجولة الخضراء 37238006004). قرار §3.3 بالخطة: لا يُشغَّل مساران خارجيان معًا إلا بقرار مالك (ازدواجية غير ضرورية)، فالمرآة لا تُفعَّل مع Drive الحي. الخطوات أدناه تبقى صالحة حرفيًا **إذا قرر المالك تفعيل المسار البديل لاحقًا** (تعذر Drive مثلًا، أو تفعيل R2 وفق شرط §3.6) — وإلى ذلك الحين يبقى `external-mirror.yml` ساكنًا بتصميمه ولا يُنشأ السر `EXTERNAL_MIRROR_TOKEN` ولا المتغيران.
> **قانون الخصوصية (إلزامي):** مستودعا الوجهة **خاصان (PRIVATE) دائمًا** — مستودع النسخ يحمل PII (إيميلات/أسماء مستخدمين). مرآة عامة لمستودع النسخ = تسريب بيانات.

## 1. قرارات قبل البدء (دقيقة واحدة)

| القرار | الخيارات | التوصية |
|---|---|---|
| المزود الخارجي | GitLab · Bitbucket · حساب GitHub **آخر** (منفصل عن `muscleshubfit-cpu`) | أي مزود تثق به وتجيد إدارته — الأهم أن يكون **حسابًا مختلفًا** عن الحساب الحالي |
| مستودعا الوجهة | مستودعان فارغان خاصان جديدان | `alkemos-mirror` + `musclehubeg-backups-mirror` (الاسمان مثالان — سمِّ ما تشاء وسجلّ العناوين في الخطوة 3) |
| من يشغّل المرآة | الـ workflow الأسبوعي (موثق أدناه) أو cron على جهازك | الـ workflow — صفر صيانة، ويعمل من GitHub طالما GitHub حي (وهذه هي الفترة التي تهم) |

## 2. إنشاء مستودعي الوجهة (على المزود الخارجي)

1. أنشئ مستودعًا **خاصًا فارغًا** (بدون README/ترخيص — فارغ تمامًا) لمرآة الكود.
2. أنشئ مستودعًا **خاصًا فارغًا** ثانيًا لمرآة النسخ الاحتياطية (PII).
3. دوّن عنواني HTTPS الخاصين بهما (سنحتاجهما في الخطوة 4).

## 3. إنشاء توكن الدفع على المزود الخارجي

- أنشئ Access Token على المزود الخارجي بصلاحية **قراءة/كتابة مستودعات فقط** (repo read+write) — وبأضيق نطاق يسمح به المزود (مثلاً على المستودعين المحددين فقط إن كان المزود يدعم النطاق الضيق).
- **لا** تمنحه صلاحيات حذف مشاريع/إدارة حساب/SSH keys.
- احتفظ بالقيمة مؤقتًا (ستضعها في الخطوة 4 ثم تنساها — لا تحفظها في ملف).

## 4. الضبط على GitHub (ثلاث خطوات في إعدادات المستودع)

في `muscleshubfit-cpu/alkemos` ▸ **Settings ▸ Secrets and variables ▸ Actions**:

1. تبويب **Secrets ▸ Actions** ▸ `New repository secret`:
   - الاسم: `EXTERNAL_MIRROR_TOKEN` — القيمة: توكن المزود الخارجي من الخطوة 3.
2. تبويب **Variables** ▸ `New repository variable` (مرتان):
   - `MIRROR_REMOTE_MAIN` = عنوان HTTPS لمرآة الكود (من الخطوة 2.1)
   - `MIRROR_REMOTE_BACKUPS` = عنوان HTTPS لمرآة النسخ (من الخطوة 2.2)
3. (لا شيء آخر — `BACKUP_REPO_TOKEN` موجود مسبقًا وسيُستخدم لاستنساخ المستودع الخاص داخل الـ workflow.)

## 5. التشغيل والتحقق (مرة واحدة، ثم آليًا أسبوعيًا)

1. من تبويب **Actions** ▸ `External mirror` ▸ `Run workflow` ▸ `Run` (تشغيل يدوي أول).
2. انتظر النجاح الأخضر — سطرا التحقق المتوقعان في اللوج:
   - `ok: alkemos — main <sha> mirrored (SHA match verified)`
   - `ok: musclehubeg-backups — main <sha> mirrored (SHA match verified)`
3. تحقق إضافي مقترح: استنسخ مرآة واحدة من المزود الخارجي على جهازك وافتح أي ملف — إثبات اكتمال.
4. من هذه اللحظة: الجدولة الأسبوعية (الأحد 06:00 UTC) تعمل وحدها — راقب أول تشغيل مجدول ثم اكتفِ بفحص عابر شهريًا.

## 6. التشغيل البديل من جهازك (اختياري — cron محلي)

```bash
MAIN_TOKEN=<توكن-قراءة-جيت-هاب-للمستودع-الخاص> \
MIRROR_TOKEN=<توكن-المزود-الخارجي> \
MIRROR_REMOTE_MAIN=https://<المزود>/<حسابك>/alkemos-mirror.git \
MIRROR_REMOTE_BACKUPS=https://<المزود>/<حسابك>/musclehubeg-backups-mirror.git \
  bash scripts/external-mirror/mirror.sh
```

نفس السكربت، نفس التحقق (exit 0 فقط عند تطابق SHA) — يصلح لجدولة محلية أضيق (يوميًا مثلًا) إن رغبت.

## 7. معيار نجاح البند P0-1 (من الخطة)

مرآتان خارجيتان خاصتان تحتويان آخر commit خلال ≤7 أيام من أي دفعة + تمرين استنساخ واحد موثق (الخطوة 5.3) — بعدها يُغلق العائق B2.

## 8. التراجع / الإيقاف

- إيقاف مؤقت: Actions ▸ External mirror ▸ `⋮` ▸ Disable workflow (أو احذف مشغّل `schedule` من الملف).
- إيقاف نهوي: احذف المستودعين الخارجيين + `EXTERNAL_MIRROR_TOKEN` + المتغيرين — الكود المصدري للسكربت لا يفعل شيئًا بدونهما.
