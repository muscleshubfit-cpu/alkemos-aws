# سياسة الصور المتوافقة مع شروط Amazon — متجر Alkemos Product Store (EN)

> **الحالة:** **معتمدة** بأمر المالك بتنفيذ المرحلة صفر (حسم خيار «أيقونات أولًا أم صور مملوكة» بالتقرير الحاكم §2/المرحلة 0-2د: **كلاهما مسموح بمحظورات صارمة** — الأيقونات هي الوضع الافتراضي البصري، والصور المملوكة/المرخصة مسموحة عند توفرها). **الإصدار 2 — أمر المالك (تنفيذ المرحلة الأولى، 2026-11-26):** أُضيف §0 «قانون الصور — المنع المطلق» (منع مطلق لصور النساء والمحتوى غير المرغوب) كقاعدة ملزمة لجميع مراحل المتجر بلا استثناء، مع حارس آلي واختبارات ومراجعة بصرية قبل اعتماد أي صورة. هذه السياسة ملزمة للمرحلة 1 (تصميم البطاقات + حقل `image_url`) وحرّاسها (§3.4-4 + §0 أدناه).
> **الأساس الرسمي (موثق بتحقق 2026-11-25 UTC):** Program Policies — رخصة IP، البند (h) — الاقتباس الحرفي بقانون المتجر §1.7: تخزين **ملف** صورة من Product Advertising Content **محظور** · تخزين **رابط** صورة مسموح ≤24 ساعة (من API) · تخزين **ASINs** مسموح لغير مدة محددة. والبند (t): مراجعات وتقييمات النجوم لا تُعرض إلا بقناة API وشروطها (غير محسومة حتى فحص المرحلة 4).

## 0) قانون الصور — منع مطلق (أمر المالك 2026-11-26 · ملزم لجميع مراحل المتجر)

### 0.1 المنع المطلق لصور النساء والفتيات

**يُمنع منعًا تامًا استخدام أو عرض أي صورة تحتوي على امرأة أو فتاة، دون أي استثناء.**

يشمل المنع:

1. صور النساء والفتيات والعارضات في صور المنتجات.
2. الصور الدعائية والتسويقية وصور نمط الحياة.
3. الرسوم التوضيحية والشخصيات الكرتونية والمولدة بالذكاء الاصطناعي.
4. الصور التي تظهر فيها امرأة في الخلفية أو بصورة جزئية أو منعكسة.
5. صور الملابس النسائية التي تعرض عارضات أو أجسادًا بشرية أو دمى عرض بشرية.
6. صور الفئات والمنتجات والأغلفة والمعاينات المصغرة ووسائل التواصل الاجتماعي.

**البدائل المسموحة:**

- صور المنتج وحده دون أي شخص أو جسم بشري.
- تصوير الملابس والمنتجات بصورة مسطحة (Flat Lay) بلا عارضين.
- الأيقونات والرسوم الأصلية المجردة.
- صور المعدات والأدوات والأجهزة دون ظهور أشخاص.

**قاعدة الرفض التلقائي:** إذا تعذر التأكد من خلو الصورة تمامًا من النساء والفتيات، **تُرفض** ويُستخدم بدلًا منها رمز بصري محايد (أيقونة محفورة من ورقة أيقونات النظام البصري — البديل الافتراضي §1/ص-1).

**الفئات النسائية لا تُحذف من التصنيف بسبب هذا المنع:** فئة «Women's Training Apparel» (فروع `training-apparel-footwear`) تبقى بالتصنيف المعتمد — منتجاتها تُعرض بصور منفصلة لا تحتوي على أشخاص (تصوير المنتج وحده/Flat Lay) أو بأيقونة محفورة.

### 0.2 منع مطلق للمحتوى غير المرغوب (الجنسان)

يُمنع منعًا تامًا استخدام أو عرض أي صور تتضمن (يسري على الجنسين وعلى جميع الصور دون استثناء):

1. النساء والفتيات، سواء بصورة حقيقية أو رسوم أو شخصيات كرتونية أو صور مولدة بالذكاء الاصطناعي (§0.1).
2. الرجال في حالات العري أو شبه العري، أو بملابس تكشف مناطق حساسة من الجسم.
3. الأعضاء التناسلية أو المشاهد الجنسية أو الإيحاءات الجنسية.
4. صور الملابس الداخلية أو ملابس السباحة أو المنتجات التي تُعرض على أجساد شبه عارية.
5. الأشخاص في الخلفية أو الانعكاسات أو الصور الجزئية إذا تضمنت أيًا مما سبق.

يشمل المنع صور المنتجات والأغلفة والإعلانات والفئات والمعاينات المصغرة ووسائل التواصل الاجتماعي.

**البدائل المسموحة (الجنسان):** صور المنتجات وحدها دون أشخاص · صور الرجال بملابس رياضية محتشمة وكاملة التغطية · تصوير الملابس دون عارضين أو أجساد بشرية · الأيقونات والرسوم التجريدية والمعدات الرياضية.

### 0.3 آلية الإنفاذ (ملزمة — تُبنى بالمرحلة 1)

- **حارس آلي عند الإدخال/النشر:** فحص برمجي لكل قيمة `image_url` وحقل وصف الصورة/alt — يرفض النشر عند أي إشارة أنثوية (نمط الحارس القانوني 173 `src/lib/image-safety.ts`: `hasFemaleSubjectSignal`) أو إشارة عري/إيحاء، وعند أي نطاق صور أمازون (بند h) — التفصيل بـ§4.
- **اختبارات كاناري:** اختبارات حرّاس الصور داخل بطارية vitest تفشل أي انحدار (اختبار مستقل لحرّاس المتجر — §4).
- **مراجعة بصرية قبل الاعتماد:** أي صورة مرفوعة/مستوردة تمر بمراجعة بصرية بشرية (المالك) قبل اعتمادها ونشرها — البوابة البشرية جزء من سير مراجعة 0097 (لا نشر بلا موافقة مالك).
- **عند الشك: ترفض الصورة تلقائيًا** ويُستخدم البديل البصري المحايد (أيقونة محفورة) — قاعدة §0.1 نفسها.
- **القانون يسري على كل أسطح المتجر بلا استثناء:** الصور المرفوعة والمستوردة والمولدة · صفحات الفئات والمنتجات · المختارات · الإدارة (`/admin/store`) · المعاينات · وحدات التوزيع (المرحلة 2) · وسائل التواصل.

## 2) المحظورات (بلا استثناءات قبل المرحلة 4 وما بعدها)

1. **صور أمازون (Product Advertising Content):** لا تخزين ملف · لا نسخ إلى استضافة Alkemos (بند h حرفيًا) · لا تخزين روابطها كبيانات دائمة (رابطها مسموح ≤24 ساعة من API فقط — المرحلة 4).
2. **تعديل صور أمازون أو التراكب عليها** (نص/شعارات/بادجات) — محظور دائمًا حتى بقناة API.
3. **مراجعات العملاء وتقييمات النجوم** بكل صورها (لقطات/نسخ نصوص/نجوم مرسومة توحي بها) — البند (t): لا عرض إلا بقناة API وشروطها (المرحلة 4 — وعرضها حينها «غير محسوم» حتى الفحص).
4. **لقطات أسعار أو «أرخص سعر»** — صفر أسعار قبل API أصلًا (شرطا الأسعار أ/ب الموثقان) — ومنع تتبع/تنبيه الأسعار (بند y).
5. **علامات أمازون التجارية** بهوية المتجر أو ترويجه — هوية المتجر «Alkemos Product Store» خالية من علامات أمازون (قواعد العلامات بقانون المتجر §1.7)؛ ذكر «Amazon Associates» نصًا بالإفصاح مسموح.
6. **قوانين الموقع الأعلى (تسري على كل صورة تسويقية للمتجر):** لا نساء/فتيات بأي صورة (قانون 173 — حارس canary) · لا مشاهد/منتجات كحول أو خنزير (قانون الحذف الثقافي 2026-11-12) · صفر إيموجي بأسطح التسويق (DESIGN.md).
7. **صور مجهولة المصدر/بحث صور عام** — أي صورة بلا ملكية/رخصة موثقة (§1) ممنوعة.

## 3) المرحلة 4 (بعد تفعيل Creators API — شرطها الموثق: 10 مبيعات مؤهلة/آخر 30 يومًا)

- صور المنتجات من **بيانات API حصريًا** عبر روابطها: كاش ≤24 ساعة (بند h) · إعادة الجلب ضمن المزامنة الليلية · **لا نسخ للملفات أبدًا** · الرابط مصحوبًا برابط صفحة المنتج ووفق شروط الرخصة.
- عند عرض محتوى نصي من API: إخلاء البند (k) الحرفي (محفوظ نصًا بـ`docs/store/DISCLOSURES-EN.md` §5).
- ما تعيده الواجهة عن المراجعات/التقييمات يُفحص فعلًا قبل أي عرض — **غير محسوم** (قانون المتجر §1.7).

## 4) حرّاس التنفيذ (تُبنى بالمرحلة 1 — قانون المتجر §3.4 + قانون الصور §0.3)

- **حارس حقل `image_url`:** يرفض أي قيمة من نطاقات صور أمازون (منع ملفات وصور أمازون — بند h) + **حارس المنع المطلق (§0):** يرفض أي إشارة أنثوية/عري/إيحاء بصور المتجر ووصفها (كاناري 173 + امتداد المتجر) + فحص أن الصورة ليست بعارضين (قاعدة الرفض التلقائي عند الشك — أيقونة محفورة بديلًا).
- **فحص النشر:** بوابة الحلال (كلمات منع على الوصف/المكونات) تشمل مسار الصور المرئي (لا صور كحول/خنزير).
- **تدقيق ربع سنوي (SOP §5.2):** «لا صور أمازون مخزنة» بند دائم بقائمة الامتثال — يفحص النسخ إلى bucket ‏`store-products` (امتلاك/رخصة فقط) · بند «لا نساء بأسطح المتجر» بند امتثال دائم كذلك (§0).
