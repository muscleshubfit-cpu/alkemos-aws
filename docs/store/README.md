# docs/store/ — الوثائق الحية لمتجر منتجات الأفلييت (Alkemos Product Store × Amazon Associates US)

> **النطاق (قانون الفصل الثلاثي — التقرير الحاكم §0):** هذا المجلد يخص **النظام 2 حصرًا** — متجر منتجات الأفلييت **الإنجليزي** المرتبط بحساب Amazon Associates الأمريكي (المتعقب `ahmedzake-20` — قيمة مقررة من المالك). **لا يمس** نظام شركاء الموقع الحالي (النظام 1) ولا المتجر العربي المستقبلي (النظام 3 — خارج النطاق بلا افتراضات). المتجر بكل طبقاته إنجليزي فقط: لا `/ar/store` ولا أعمدة `_ar` ولا مرايا hreflang.
> **القانون الحاكم الأعلى:** `docs/archive/ALKEMOS-STORE-AFFILIATE-READINESS-AUDIT-2026-11-26.md` (الإصدار 2 المصحح — **اعتُمد قانونًا حاكمًا للمتجر بأمر المالك مع تنفيذ المرحلة صفر**، التوثيق: `docs/archive/ALKEMOS-STORE-PHASE-0-EXECUTION-2026-11-26.md`). عند أي تعارض: التقرير الحاكم يعلو، وهذه الملفات تكملة تنفيذية لقراراته.
> **الحالة:** المرحلة صفر منفذة (توثيقي خالص — صفر كود/ميجريشن/إنتاج)؛ **المرحلة 1 مُجهّزة للفتح** (نطاقها التنفيذي موثق بـ`PHASE-1-SCOPE.md` — لا يبدأ أي تنفيذ قبل أمر مالك) · **بيانات الدفع/الضرائب بالحساب مكتملة (حقيقة معتمدة من المالك — لا خطوة معلقة)** · التصنيف الموسع v2 (12 رئيسية/3 موجات) **بانتظار اعتماد المالك**.

## قواعد هذا المجلد

1. **اللغة:** هذه وثائق حوكمة داخل المستودع (عربية) — أما **مخرجات المتجر نفسها** (الواجهة، التصنيفات، نصوص الإفصاح، المحتوى التحريري، alt الصور) فبالإنجليزية حصرًا. النصوص القانونية الإنجليزية تُنقل حرفيًا بلا ترجمة.
2. **كل رقم أمازوني** (نسبة، شرط، نافذة) لا يُكتب هنا إلا بمصدر رسمي وتاريخ تحقق (قانون المصادر بالتقرير الحاكم §6) — وما تعذّر إثباته يُصاغ «غير محسوم». **نسب العمولات داخلية حصرًا:** لا تُعرض للزوار ولا تُستخدم تسويقيًا (قانون العرض بأمر المالك 2026-11-26 — تفصيله برأس `COMMISSION-RATES.md`).
3. هذه الملفات مرجع **المرحلة 1+** (ميجريشن `0115_store_foundation` + الإدارة + الصفحات EN): كل بند تنفيذي يستشهد بها أو بالتقرير الحاكم — ونطاق المرحلة 1 المجمّع بـ`PHASE-1-SCOPE.md`.
4. التحديثات اللاحقة لهذه الملفات توثق بأمر المالك المرتبط بها وتسجل بworklog وSTATE كالمعتاد.
