## قواعد هذا المجلد

1. **اللغة:** هذه وثائق حوكمة داخل المستودع (عربية) — أما **مخرجات المتجر نفسها** (الواجهة، التصنيفات، نصوص الإفصاح، المحتوى التحريري، alt الصور) فبالإنجليزية حصرًا. النصوص القانونية الإنجليزية تُنقل حرفيًا بلا ترجمة.
2. **كل رقم أمازوني** (نسبة، شرط، نافذة) لا يُكتب هنا إلا بمصدر رسمي وتاريخ تحقق (قانون المصادر بالتقرير الحاكم §6) — وما تعذّر إثباته يُصاغ «غير محسوم». **نسب العمولات داخلية حصرًا:** لا تُعرض للزوار ولا تُستخدم تسويقيًا (قانون العرض بأمر المالك 2026-11-26 — تفصيله برأس `COMMISSION-RATES.md`).
3. هذه الملفات مرجع **المرحلة 1+** (ميجريشن `0115_store_foundation` + الإدارة + الصفحات EN): كل بند تنفيذي يستشهد بها أو بالتقرير الحاكم — ونطاق المرحلة 1 المجمّع بـ`PHASE-1-SCOPE.md`.
4. التحديثات اللاحقة لهذه الملفات توثق بأمر المالك المرتبط بها وتسجل بworklog وSTATE كالمعتاد.
