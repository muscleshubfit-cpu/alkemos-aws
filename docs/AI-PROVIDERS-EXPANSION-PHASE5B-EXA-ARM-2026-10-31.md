## 3) تغييرات الكود (بمسارات وأرقام)

### 3-أ) ذراع Exa — `src/lib/ai-provider.ts`

- **`callExaSearch(prompt, options)`** (~1,539–1,690): (1) فحص المفتاح → خطأ صادق بلا نداء؛ (2) تبريد `grounded:exa` كقانون الأذرع؛ (3) **قانون الاستعلام:** إنجليزي → `options.searchQuery`؛ عربي → `options.searchQueryEn` (الإنجليزي المكافئ — خريطة Exa الدلالية قاست 2/40 عربية فقط) وإلا قص أول 400 محرف من البرومبت بتحذير مسموع؛ (4) نداء POST `api.exa.ai/search` بترويسة `x-api-key` وجسم `{query, numResults:10, type:"auto"}` (+`includeDomains` اختياريًا) — الشكل المقيس بالمرحلة 3؛ (5) **بوابة الدليل الحية:** استخراج `{title,url}` من `results[]` (فسَلت 12 كحد أقصى بنمط `mergeDedupedSources`) — صفر URLs = فشل صادق ينتقل للذراع التالية؛ (6) **التعميق الاختياري §12-2:** نداء واحد `api.exa.ai/contents` بجسم `{ids: أعلى 3 روابط, text:{maxCharacters:5000}}` (الشكل الفائز المقيس 24/24) — وعند فشله نداء بديل واحد `api.tavily.com/extract` بجسم `{urls}` (رصيد واحد لكل 5 روابط بالخطة المجانية نفسها) إن كان مفتاح Tavily حاضرًا والذرعة غير مبرّدة — وكل فشل **لين**: حزمة snippets بختم `researchDepth:"snippets"` (لا يفشل المقال أبدًا — قانون §6-أ)؛ (7) **التوليف:** برومبت = نتائج البحث المرقمة (روابط + مقتطفات `text` + التاريخ publishedDate + **النص الكامل المستخرج** لأعلى 3 بحد 1,200 محرف/صفحة داخل البرومبت) + ملاحظة المهايئ + البرومبت الأصلي → `callFreeAIFallbackChain` (سلسلة التدوير) بميزانية الوقت المتبقية؛ (8) العائد: `{text, provider:"exa", model:نموذج التوليف, grounding:{searchQueries:[query], sources}, researchDepth, fullText}`.
- **العقد الموسع:** `GroundedSearchArmProvider = AIProvider | "tavily" | "exa"` · `GroundedSearchOptions += searchQueryEn` · `GroundedSearchResult += researchDepth? + fullText?` (حقول اختيارية — العقد الأساسي [نص + مصادر + تتبع] لم يتغير؛ الأذرعة القديمة والمشي بلا تعميق تُرجعه بلا الحقلين).
- **مقابض التشغيل:** `EXA_NUM_RESULTS` (10) · `EXA_CONTENTS_MAX_CHARS` (5,000 — يشترك مع قص raw_content لذراع Tavily) · `EXA_INCLUDE_DOMAINS` (فارغ افتراضيًا — قانون الاقتباس الصادق محسوم للبوابات P4/P5) · `GROUNDED_ARM_ORDER` (تجاوز ترتيب السلم كله بلا نشر — تشخيص/تراجع) — كلها بلا نشر.

### 3-ب) السلم النهائي المقسوم باللغة — `groundedArmOrder` + `callGroundedSearch`

- **الترتيب (المعتمد §12-1، الحالة النهائية):** `en → ["exa","tavily","groq","gemini"]` · `ar → ["tavily","groq","exa","gemini"]` · بلا `lang` → الإنجليزي (عقد بحث JSON بمفاتيح إنجليزية بالبناء — المسبار يركب نفس الافتراض). `GEMINI_GROUNDED_ENABLED=0` يزيل الذرعة الخامدة؛ `GROUNDED_ARM_ORDER` يتجاوز الكل (قيمة غير صالحة = السلم المدمج). [تصميم §6-أ → منفذ]
- **مشي `callGroundedSearch`:** فرع `exa` مضاف؛ رسالة الخطأ التجميعية تسمّي السلم المقيس باللغة وتسمّي كل ذرعة بحالتها بصدق (واسم التجاوز إن فُعّل).
- **`blog-research.ts`:** `searchQueryEn: TAVILY_SEARCH_QUERY_EN` يُمرّر دائمًا (المكافئ الإنجليزي للعربية؛ الإنجليزية تستخدم `searchQuery` نفسه) + إرفاق `researchDepth`/`fullText` بالحزمة إرفاقًا سلطويًا من نتيجة الذراع (صدى JSON النموذج لا يصنع دليلًا أبدًا) + النوع `LanguageResearch += researchDepth?/fullText?` (اختياريان — صفوف ما قبل 5-ب بلا الحقلين ومساراتهم بایت-مطابقة).
- **`blog-pipeline.ts` `researchDigest`:** عند توفر `fullText` يُضاف كتلة «RESEARCH DEPTH: … FULL TEXT of the top N evidence pages» بكل صفحة (رابطها + مقتطف 1,200 محرف) إلى برومبت P1 — غيابه = الهضم بایت-مطابق لما قبل 5-ب (قانون «فشل التعميق = حزمة عادية»). **قرار تنفيذي موثق:** §10-ب يسمّي مسار researchDigest حصرًا فلم يُمس سياق P2 (VERIFIED SEARCH CONTEXT) — الأدلة العميقة تشكّل JSON البحث الذي يركب الهضم إلى P1 الذي يشكّل تعليمات P2، وبقاء سطح P2 كما هو يبقي معايرة بوابة الكتابة بلا اضطراب.

### 3-ج) ذراع Tavily — الختم المجاني

- نتائج بحث Tavily تحمل `raw_content` أصلًا (منذ 5-أ: `include_raw_content:true` — قيس حتى 22,155 محرفًا/صفحة): أعلى 3 صفحات بروابطها تُرفق كـ`fullText` (قص 5,000) بختم `researchDepth:"full-text"` — **صفر نداءات إضافية** (استهلاك جسم الاستجابة القائم)؛ لا raw_content → ختم `"snippets"` الصادق. اختبار ثابت أن عدد نداءات الذرعة لم يزد (بحث + توليف = 2).

### 3-د) المسبار الحي — `scripts/ai-grounded-failover-probe.mts`

- ذراع Exa تُقاس **أولًا** بترتيب السلم الإنجليزي (بحث + تعميق + توليف — يطبع researchDepth وصفحات النص الكامل وأحرفها) ثم tavily ثم groq ثم gemini الخامدة ثم OR تشخيصًا خارج السلم.
- **بند §13-6 التكميلي (~$0.004):** بحث Exa واحد مقيّدًا بـ`includeDomains` على 3 نطاقات سلطات (nih.gov · who.int · mayoclinic.org) — يطبع نطاقات النتائج ونسبة الالتزام للفحص البشري (سلوك غير مقيس سابقًا).
- **المشيان الشاملان:** إنجليزي (`lang:"en"`) وعربي (`lang:"ar"` + استعلام عربي + المكافئ الإنجليزي) — حكم الخروج: أخضر فقط إذا أجاب كل مشٍ بمزود ما بإجابة مبنية على بحث حي (اللغة سلوك إنتاجي فوجب قياسهما معًا).
- **قانون الجودة (قرار 7):** المصادر وعينة الإجابة مطبوعان لكل ذرعة وكل مشٍ — نجاح الاتصال وحده لا يصدر حكمًا.
