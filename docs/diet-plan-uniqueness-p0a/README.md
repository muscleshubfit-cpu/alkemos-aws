**استبدال الكتل المشتركة الخمس (دليل المستوى ×2 توقيع · دليل النظام ×2 · أسئلة FAQ الخمس · فقرة الأرقام · نص بطاقة التخصيص والتسميات التوضيحية) بمحتوى تحريري فريد لكل خلية يخفض احتواء 5-gram داخل العائلة من 0.70–0.77 إلى 0.17–0.21 (خفض 3.8–4.3×)، وهو يبلغ أرضية الموقع الفعلية للصفحات الفريدة المثبتة بضابطين حيين (مدونة فريدة بطول الخلايا: 0.152 · أطعمة فريدة أقصر: 0.368) — أي أن البقايا المقيسة بنية (كروم الموقع + جدول الخطة المحسوبة) لا تحريرية، والمسودات الجديدة فيما بينها شبه معدومة التشابه (0.00–0.11).**
