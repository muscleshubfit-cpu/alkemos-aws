+      .order("created_at", { ascending: true })

- **نطاق التعديل محصور بADOPT**: `findResumableRow` و`findResumePairCandidate` بقيتا «الأحدث أولًا» **عن قصد** (الاستئناف يريد أحدث عمل معلق) — ومثبّتتان باختبار تباين (CONTRAST PIN) كي لا ينتشر القلب صامتًا إليهما يومًا.
