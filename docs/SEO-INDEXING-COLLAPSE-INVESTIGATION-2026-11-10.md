## 13. حدود القياس المصرّح بها (كال قانونًا)

1. **تقرير Page Indexing (Coverage) غير متاح عبر API** — أعداد الفئات وعيناتها (§3) من تصدير المالك بتاريخ بيانات 2026-10-12؛ تحديثها لتاريخ التقرير يتطلب تصديرًا جديدًا (P0-3). لا ادعاء هنا بأن أعداد الفئات «بتاريخ 09-11».
2. **لا سجلات وصول على الأصل** (Caddy بلا `log` — توصية P3-1) — لا يُرى Googlebot الحقيقي في سجلات الخادم؛ تعويض جزئي من CF API ممنوع (صلاحية analytics غير ممنوحة للتوكنات — مقيس مرتين).
3. **Wayback Machine بلا أي لقطة للموقع بين 09–10/2026** (موقع فتيّ — مقيس CDX/availability هذه الجلسة) — فلا شاهد خارجي مستقل للHTML التاريخي؛ التعويض: بوابة تكافؤ git + زحفات 10-18/10-31/11-05 الموثقة.
4. **`site:` عبر أدوات خارجية غير موثوق** (المشغل يُتجاهل — مقيس 10-18 §6.2) — استُخدم فحص بحث نوعي فقط (§8) لا كعدّاد فهرس.
5. عدد الصفحات المفهرسة فعليًا بتاريخ التقرير غير قابل للقياس المباشر من الجلسة — أقرب مؤشر: بصمة الظهور (37 صفحة ظهرت مرة واحدة على الأقل في 28ي) + الفحص الخارجي النوعي.
