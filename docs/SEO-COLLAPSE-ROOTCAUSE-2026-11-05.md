# SEO-COLLAPSE-ROOTCAUSE — التحقيق العميق في انهيار الظهور العضوي: التصحيح الحاكم والإصلاح التقني المثبت (2026-11-05)

> **الإطار (أمر المالك 2026-11-05):** تحقيق تقني عميق لتحديد السبب الجذري لانهيار الظهور العضوي بعد الانتقال من Vercel إلى AWS بتاريخ 2026-10-10، بأولوية صريحة لفرضية «خلل تقني ناتج عن الهجرة». المطلوب: مراجعة كل ما سبق دون تكرار، مقارنة المستودعين والبيئتين، فحص عملي حي (Googlebot/status/SSR/robots/sitemap/canonical/hreflang/redirects/headers/caching/DNS/TLS/اختلاف المستخدم عن المحرك)، فحص السجلات وربط أي خلل بتوقيت الانهيار، إثبات السبب بالأدلة، تنفيذ الإصلاح التقني إذا ثبت واختباره على الإنتاج، ثم التوثيق الكامل.
> **المنهجية:** أدوات قياس جديدة لم تتوفر لأي تحقيق سابق — **توكن Vercel API** (تقرير 2026-10-18 نصّ حرفيًا: «تعذر قراءة سجلات Vercel الخام (لا توكن Vercel بالجلسة)») أتاح سلسلة الاستخدام الساعية/اليومية الكاملة لنافذة الانهيار · توكنات Cloudflare API لقراءة القواعد والإعدادات · تشغيلان طازجان لسير `gsc-connection-test` (run ‏42043224771 — نافذة 28 يومًا + سلسلة يومية) وسير `seo-followup-log-probe` (run ‏42045014872 — قراءة سجلات الخادم لحظيًا) · زحف حي 27 URL × 3 هويات (متصفح/Googlebot/Bingbot) · مقارنة git-tree للمستودعين لحظة القطع · فحص بحث خارجي للفهرس الحالي. **كل رقم أدناه مقيس بهذه الجلسة أو مستشهد بمصدره داخل المستودع.**

### 3.5 الزحف الحي اليوم (27 URL × 3 هويات — المستخدم مقابل محرك البحث)

**الهويات:** متصفح Chrome حقيقي · Googlebot/2.1 · bingbot/2.0. **النتيجة الكاملة:**

- **27/27 × 3 = كلها HTTP 200** بنفس حجم الاستجابة **بايت-ببايت** لكل صفحة عبر الهويات الثلاث (لا اختلاف مستخدم/زاحف إطلاقًا — لا cloaking ولا حجب UA).
- العينة تغطي: الرئيسية EN/AR · الأدوات · coaching · memberships · programs · diet-plan · meal-planner · AI planners · exercises (+صفحة تمرين) · foods (+صفحة طعام) · compare · faq · about · authors · blog · evo · llms.txt · rss.xml · www · http.
- **الإشارات داخل HTML (Googlebot):** canonical ذاتي 100% · hreflang كامل en/ar/x-default (والاتجاه المعكوس صحيح للصفحات AR) · `<meta name="robots" content="index, follow">` بلا استثناء · عناوين سليمة · **صفر `X-Robots-Tag` على أي استجابة** (مسحت كل الهيدرز المحفوظة).
- **التحويلات:** `http://` → 301 https ✓ · `www` → 301 apex ✓ · شرطة ختامية → 308 للمسار النظيف ✓ · حالة كبيرة → 404 (سلوك قياسي) ✓ · TTFB ‏0.04–1.26 ث عبر CF (كاش HIT غالبًا).
