### 3.3 المساعد الذكي EVO [مقيس]

- **دورة الطلب** (`POST /api/ai/chat`): درع الأزمة أولًا (رد ثابت بلا موديل ولا حصة) → حد يومي (`evo_chat_usage` أعضاء: مجاني 10/يوم، مدفوع بلا حد؛ `evo_anon_usage` مجهول بهاش IP: 10/يوم) → تصنيف نية (regex بلا AI) → بوابة بوول الخطط لنيات الخطة → بحث منصي محلي (`evo-search.ts` على فهارس التمارين/الأطعمة/البرامج) → «RAG» المدونة (استعلام ilike على blog_posts منشور بنفس اللغة، 3 نتائج) → سياق المشترك + ذاكرة (15 حقيقة) → **تسجيل الاستخدام قبل الإرسال** → كاش (0081، أسئلة بلا سياق، تشابه ≥0.92، TTL 48س، يحفظ التكلفة لا الحصة) → **نداء الموديل**: `callFreeAIFallbackChain` سلسلة fast، وسم `evo-chat`، 800 توكن، 16ث، maxModels 3، **بث توكنات حي** (SSE delta) → تنظيف (نزع reasoning/markdown/LaTeX) → رد محلي عند الفشل المبكر/الفارغ.
- **البحث الخارجي: غير موجود في المحادثة** — لا grounded ولا Tavily ولا غيرهما؛ `external-search.ts` كود ميت بلا مستوردين.
- **استخراج الذاكرة** (كل 10 رسائل، `route.ts:954`): سلسلة fast، وسم `evo-memory`، 400 توكن، 12ث، maxModels 2 — تحقق ≤5 حقائق × ≤300 محرف مع إزالة تكرار وقائمة نفي PII.
- **التقييم الأسبوعي** (`evo-weekly-eval.yml` خميس 21:00 UTC): 10 أسئلة مرجعية (6 ع + 4 إ) بالإجابة عبر السلسلة (وسم `evo-eval`) وقاضٍ رخيص (وسم `evo-eval-judge`) — **بلا GEMINI_API_KEY بالسير** (فجوة أمانة §4/ب7). الصفر المسجل = أحمر صادق بلا علاج آلي بعده.
- **المتابعات/التغذية الراجعة: بلا AI** (بريد Brevo حتمي + إدراج خدمي). **التعلم الأسبوعي حتمي صفر LLM.**
- **عداد الاستخدام:** `evo_call_stats` صف لكل نداء (موديل/كاش/محلي) تقرأه لوحة `/admin/evo-analytics`.

## 6) التصميم المعماري الموحد لتوزيع المهام [تصميم — لا كود قبل الموافقة]

> **المبادئ الحاكمة:** (1) بوابة الدليل الحية تسري على كل ذراع بحث جديدة حرفيًا — إجابة بلا URLs = فشل صادق (قانون 344). (2) قانون gemini-first (343) وقانون الجودة أولًا لا يمسان: سلاسل التوليد الثقيلة كما هي؛ CF للأدوار الرشيقة الجديدة فقط. (3) كل انتقال مشروط ومحدود وموسوم — لا دوران مفتوح. (4) لا يُنقل أي دور لمزود جديد قبل **مسبار الدور الوظيفي** (مسار الكود الحقيقي لا اختبار API عام) — قاعدة المالك الصريحة.

### 6-أ) سلّم البحث المُسنَد الجديد (P0) — مقسّمًا باللغة

```
استعلام عربي:   Tavily (أساسي, 1 رصيد) → Groq browser_search (120b→20b) → Exa (بالاستعلام الإنجليزي المكافئ) → [Gemini googleSearch خامدة بتبريد]
استعلام إنجليزي: Exa (أساسي, دلالي) → Tavily → Groq browser_search → [Gemini خامدة]
```

- **الإحلال:** ذراع OR web **تُزال من السلم الفعلي** (موديل ميت + مدفوعة — إثباتان حيان) ويبقى كودها موثقًا كميت أو يُحذف بفريم مستقل؛ Gemini googleSearch تبقى ذراعًا أخيرة خاملة لا تُطلب إلا إن عادت حصتها (تبريدها يجعلها رخيصة التخطي) مع مقترح مقبض تشغيل `GEMINI_GROUNDED_ENABLED` لتعطيلها بلا نشر إن رغب المالك.
- **العقد:** كل ذراع جديدة تُرجع `GroundedSearchResult` نفسه (نص + مصادر URLs حية + provider/model للتتبع) وتُجمّع بـ`normalizeResearch`/`researchDigest` القائمين بلا تعديل مسار الحزمة، مع ختم `researchSource:"tavily"|"exa"` على الصف (نمط الرصد القائم بqueue-health) وتبريد 30 دقيقة على 429/401/403 لكل ذراع كالقانون.
- **الاستعلام الإنجليزي المكافئ للعربية:** مسار P0 يولّد استعلامات بحث ثنائية أصلًا؛ قرار تفصيلي (تمرير الإنجليزي المكافئ لExa عند فشل Tavily عربيًا) يُعرض عند التنفيذ ضمن التصميم التنفيذي للذراع.
- **الاستخراج (جديد):** Exa `/contents` (text, ‏maxCharacters ~5000) لأعلى 3 نتائج لتعميق حزمة البحث، وTavily Extract بديلًا — **اختياري لا يفشل المقال** (فشل التعميق = حزمة عادية بلا نص كامل) ويُختم `researchDepth:"full-text"|"snippets"`.

### 6-ج) عقد الواجهة الموحد للمزود الخامس (CF) [تصميم]

- مدخل `provider:"cloudflare"` داخل `ai-provider.ts` بنفس عقد السلسلة (REST `…/ai/run/{model}`) — يُدرج كمداخل مخصصة للأدوار الرشيقة أعلاه فقط، **لا** إعادة كتابة السلاسل الثقيلة.
- متغيران قائمان بالأسرار من المرحلة الثالثة: `CLOUDFLARE_AI_TOKEN` + `CLOUDFLARE_ACCOUNT_ID` (يُضافان فارغين إلى `.env.example` + توثيق SECURITY.md **بكوميت الدمج نفسه** — قانون §3.2).

- timeout لكل دور CF: 30ث (أقصى مقيس 15.8ث + هامش)؛ مهلة السلسلة الإجمالية تحكم كما هو.

### 7-ب) بوابات المصادر والتحقق العلمي — إثبات عدم القابلية للتجاوز [مقيس]

1. **بوابة الدليل الحية** (إجابة بلا URLs = فشل) مطبقة داخل كل ذراع على حدة قبل النجاح — لا ذراع جديدة تعود بنتيجة بلا مصادر، بما فيها Tavily/Exa (التصميم يفرض نفس العقد).
2. **لا بديل محاكى:** `fallbackResearch` اختبار فقط؛ `external-search.ts` ميت بلا مستوردين؛ فشل كل الأذرع = فشل صف صادق (500 → إعادة ×3 → أحمر).
3. **المسار الاحتياطي article_generate:** بلا بحث مُسنَد (بتصميم) لكنه **لا يستطيع النشر** (is_published=false دائمًا) — البشر هم نقطة النشر، والفجوة الوحيدة (بلا بطارية عند النشر اليدوي) تُغلق بالخطة §10-د فتصير «بوابة + عين المالك».
4. **المسارات المحلية (ai-local):** لا تصلح مسودة مدونة ولا رسالة محادثة إلا عبر مسارها المحروس؛ خطة التغذية المحلية تخضع لنفس PLAN_AI_SANITY وغير الملتزم **يُرفض ولا يُحفظ**؛ خطة التدريب المحلية (غير المشروطة) نطاقها خطة مسودة بعميل — لا نشر عام ولا ادعاء مصادر.
5. **المهام الخلفية:** كلها عبر السلاسل نفسها وبوابات معالجاتها؛ الخروج غير الصفري قانون (لا نجاح كاذب)؛ لا مسار خلفي يستدعي بحثًا غير مؤرض أصلًا غير article_generate المذكور.
6. **التقييم والتدقيق مستمران بلا صلة بالتبديل:** كاناري الطبقة (8 ملفات) + مسبار plan-ai-probe + بطارية P5 — كلها تعمل أياً كان المزود الرائد.

### 8-ج) العدّاد المركزي للحصة [تصميم]

- **المصدر الرسمي:** كتلة `result.usage.neurons` بكل استجابة REST (مطابقة ترويسة `cf-ai-neurons` مقيسة نداءً بنداء؛ GraphQL رفض حقوله — موثق محجوبًا).
- **التخزين:** تراكم ذرّي INCR بمفتاح يومي UTC `cf:usage:{YYYY-MM-DD}:neurons` ببنية العدادات القائمة نفسها (Upstash REST، TTL ‏30 يومًا، fail-open) — **إعادة الضبط اليومية تلقائية** بالمفتاح الزمني 00:00 UTC بلا أي مسح.
- **الحاجزان:** تحذير عند **≥80% (8,000 عصبون)** يظهر بشرط جديد بqueue-health + التقرير الأسبوعي؛ **حاجز منع الاستنزاف عند ≥95% (9,500)**: كل نداء CF جديد يُتخطى بصدق (نفس نمط التبريد — سبب موثق بالخطأ المجمَع) وينتقل الدور للمزود التالي — الحصة لا تُستهلك بالكامل أبدًا بقرار تصميم، ويبقى هامش 5% للطلبات المتزامنة الجارية.
- **التزامن:** INCR ذرّي؛ الفحص القبلي استشاري (تجاوز محدود نظريًا بحدود التزامن المقيس بالمسبار — يوثق صدقًا).
- **التدهور:** غياب Upstash → عدّاد داخل العملية + حاجز ترويسة-فقط لكل عملية (fail-open موثق كعدادات Gemini تمامًا).
- **الميزانية المتوقعة [حساب]:** موجة أولى ~450 عصبون/يوم (4.5%) · بالموجة الثانية كاملة ~1,750 (17.5%) — كلاهما بعيد عن 80%.
