## §3 — طبقات فرض الحد (4 مقالات أسبوعيًا حتى مع إعادة المحاولة والتشغيل اليدوي)

1. **الجدولة نفسها**: فتحتان فقط لكل لغة أسبوعيًا (بنيويًا).
2. **حارس النشر اليومي** (المرحلة 171، كما هو): يرفض ثاني مقال آلي بنفس يوم الإنشاء لنفس اللغة (`skipped_daily_quota`).
3. **حارس النشر الأسبوعي الجديد** (p5-publish): يرفض المقال الآلي **الثالث** لنفس اللغة في نفس أسبوع ISO — أساس العدّ صفوف `blog_generation_queue` المنشورة المنسوبة ** لأسبوع إنشاء الصف** (نفس قانون العدّ اليومي القائم) — حالة صادقة `skipped_weekly_quota`. يعمل على كل المسارات: المجدول، تعويض الـbackstop، إعادة تشغيل الـworkflow يدويًا، وإعادة محاولة الوظائف.
4. **سقف الـbackstop البنيوي**: «المتوقع» لا يتجاوز فتحتي اللغة أسبوعيًا أبدًا + تعويض واحد لكل إطلاق — فلا يمكن للموزع تصنيع مقال ثالث.
5. صفوف الكوتش (bundleMarksCoachRequest) معفاة من الحارسين بقانون المرحلة 162 — طلب مالك صريح، وليس «تجاوزًا بسبب إعادة المحاولة أو التشغيل اليدوي» موضوع الأمر.

## §4 — ضمان اكتمال الأزواج (التقاطع مع الإيقاع الأسبوعي)

- **الاتجاه محفوظ كما هو**: الفتحة العربية تنشئ الزوج (CREATE: بحث اللغتين + استدعاء الاقتران + صفّان بـpair_id وsharedBrief مختوم)، والفتحة الإنجليزية في اليوم التالي تستهلك التوأم (RESUME/ADOPT) ثم تُكمل مصافحة P5 ‏`linked_post_id` بالاتجاهين → hreflang (sitemap-blog) + LanguageToggle يعملان لكل زوج. **لا آلية اقتران غُيّرت؛ النوافذ فقط اتسعت.**
- **حساب الفجوات الأسوأ** (سبب توسيع النوافذ 72/48/48 ساعة ← **144 ساعة** للثلاث: ADOPT/JOIN/RESUME):
  - التسليم الطبيعي: توأم أُنشئ الاثنين 05:00 يُستهلك الثلاثاء 22:00 = **41 ساعة** ✓.
  - استئناف نفس اللغة عبر نهاية الأسبوع (خميس/جمعة ← الاثنين/الثلاثاء) = **96 ساعة** ✓ داخل 144.
  - أسوأ انتظار إنقاذ لتوأم: أُنشئ الخميس 05:00 وفشلت فتحة الجمعة كليًا → الفتحة الإنجليزية التالية الثلاثاء 22:00 = **137 ساعة** ≤ 144 ✓ (التوأم يبقى قابلًا للاستهلاك عبر فجوة نهاية الأسبوع — نفس ضمان اكتمال الزوج الذي كان اليومي يحصل عليه مجانًا).
  - ما بعد 144 ساعة ينتهي الصدق (رفض الاقتران الأعمى محفوظ حرفيًا).
- **التعويض يعطي اكتمال الزوج أولوية**: أي إطلاق تعويض يستأنف الصف/التوأم المعلق قبل أي إنشاء جديد (ترتيب P0: RESUME → ADOPT → JOIN → CREATE كما هو).
- hreflang/خريطة الموقع ديناميكيان من `linked_post_id` (blog-sitemap.ts) — لم يُمسّا؛ كل زوج مكتمل يظهر تلقائيًا بنسختيه وروابطه المتبادلة في الخريطة.
