# 02 — بحث الكلمات المفتاحية وKeyword Mapping

> **منهجية الأمانة [ملزمة]:** لا تتوافر أحجام بحث شهرية دقيقة (لا أداة مدفوعة متاحة بالجلسة — نفس القيد الموثق في بحث 2026-11-05). كل «طلب» أدناه يستند إلى: (1) **قياسات GSC موثقة** (نوافذ 09-20→10-17 و10-03→10-30 + إجمالي 3 أشهر حتى 16-11)، (2) **فحص SERP حي بتاريخ 2026-11-19** (10+ استعلامات بالعربية والإنجليزية — تكوين SERP نفسه دليل طلب: وجود أدوات حكومية/تطبيقات/مواقع متخصصة)، (3) فحوص SERP مؤرخة سابقًا (2026-11-05، 2026-09-19). **يُمنع اختلاق أرقام** — أي تقدير نوعي موسوم [تقدير]. سحب الأحجام الدقيقة (Keyword Planner) = مهمة P0-G على المالك.
> **الحدود:** بيانات GSC الحالية تعكس فترة اضطراب فهرسة موثقة؛ تُستخدم هنا كمؤشر طلب تاريخي موثق لا كمعدل حالي.

## 1. خلاصة استراتيجية السوقين

| | السوق العربي | السوق الإنجليزي |
|---|---|---|
| التموضع | **هجومي — المحرك الرئيسي** | **دفاعي انتقائي** |
| الدليل | نقرات مصر الوحيدة + انطباعات KSA/IRQ/UAE (GSC #8) + SERP بلا منصة متخصصة (فحص 11-19) | أدوات EN جمعت 2,748 انطباعًا موثقًا قبل الاضطراب لكن بمواقع 78-85 — رؤوس SERP محتكرة (NHLBI/CDC/calculator.net) |

## 6. Keyword Mapping — منع تنافس الصفحات (Cannibalization Guard)

**قواعد الملكية الملزمة لأي تنفيذ قادم:**

| النية/النمط | المالك الوحيد | ممنوع على |
|---|---|---|
| «حاسبة سعرات» + «TDEE» + «احتياج يومي» (AR/EN) | calorie-calculator | macro-calculator وmeal-planner وأي صفحة أخرى |
| «ماكروز» + «بروتين كارب دهون بالغرام» + توزيعات (keto/balanced...) | macro-calculator | calorie (يعرض ماكروز بالنتيجة كقيمة إضافية لا استهدافًا رأسيًا — النص الحالي سليم) |

| «ولّد خطة بالذكاء الاصطناعي» | ai-meal-planner / ai-workout-planner (بفصل تغذية/تمرين صارم) | meal-planner |
| «متتبع/سجل شرب ماء» + «كم ماء يوميًا» | water-tracker | — |
| «مدرب اونلاين» + «تدريب شخصي أونلاين» | coaching | evo وmemberships (يحيلان إليه) |
| «منصة/برنامج للمدربين» | for-coaches | coaching (صفحتان جمهور مختلف: B2C مقابل B2B — النصان الحاليان مفصولان سليمًا) |

**حالة تنافس رصدت وفُحصت (سليمة):** macro-tracker وworkout-tracker صفحتا نية مركّبة (workflow) لا تتنافسان مع الحاسبات — تدلان وتحيلان (تقييم التفصيل في 06).

## 8. الإشارات الرقمية الجاهزة للاستثمار (AEO — من GSC موثق)

- قيم BMI الرقمية: «bmi 20»→«bmi 43» بمواقع 72-86 — الفAQ الرقمية الموجودة (أُغلقت فجوتها 2026-11-05 للماكروز ودهون الجسم) هي الأصل الصحيح؛ الباقي تحسين مواضع.
- «120g banana macros» @7.5 — نمط «{N}g {food} macros» يخدمه محتوى مرجعي للحاسبات لا صفحات جديدة.
- بحث العلامة: الرئيسية 3 نقرات/10 انطباعًا @1.1 — العلامة موجودة بهويتها (SERP براندي يعمل).
