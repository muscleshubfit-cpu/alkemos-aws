# 01 — التقرير التنفيذي النهائي: تدقيق تقني شامل لانهيار فهرسة Alkemos.com

> **معرّف المهمة:** SEO-INDEXING-AUDIT-2026-11-11 · **النوع:** تدقيق فقط (صفر تعديل كود/إنتاج/DB/إعدادات) · **النافذة:** جلسة 2026-11-10/11 · **المفوّض:** أمر المالك بتاريخ 2026-11-10/11.
> **الأدوات:** SiteOne Crawler v2.5.1 (المصدر الرسمي) + أدوات CLI مجانية مساندة + GitHub API (قراءة) + Cloudflare API (قراءة فقط) — كل الأوامر والنسخ الخام في `raw/`.

---

## الخلاصة الحاكمة في ثلاث جمل

1. **الانتقال من Vercel إلى AWS (2026-10-10) ليس سبب انهيار الفهرسة — مثبتًا بالأدلة، لا استنتاجًا:** الزحف الشامل المستقل (13,800 رابطًا) لم يجد **أي عيب تقني واحد قابل للإصلاح** في أي بُعد فهرسة: صفر أخطاء 5XX، صفر أخطاء JS/CSS، صفر X-Robots-Tag، تكافؤ بايتات كامل بين Googlebot والزائر العادي، canonical سليم 100%، وسرعة استجابة ممتازة (متوسط 271ms) — بينما الانهيار نفسه اكتمل يوم **2026-10-08** أي قبل القطع بيومين، وفق بيانات GSC الموثقة في تحقيقات المستودع السابقة.
2. **السبب الجذري المثبت هو قرار جودة/سلطة موقعي من Google** فوق موقع فتيّ (النطاق مسجل 2026-09-05 والمحتوى انطلق 2026-08-17) ببصمة روابط خارجية شبه معدومة (5–20 نطاقًا محيلًا فقط، منها Trustpilot التلقائي)، مع كتلة محتوى قالبيّة رقيقة تقيس مستقلًا عند **~250–300 كلمة للصفحة** في 74% من خريطة الموقع، وذيل زحف ضخم يقيس مستقلًا عند **~17,502 صفحة أطعمة خارج الـ Sitemap + ~9,838 صفحة ترقيم/فلترة بارامترية** يستنزف ميزانية الزحف — وهو ما يفسر آليًا حالتَي «Crawled – currently not indexed» (1,068) و«Discovered – currently not indexed» (881) في GSC.
3. **أرقام تقرير Ahrefs (10-11) المستقل حُققت بندًا بندًا:** بعضها تأكد (4 صفحات 404، اتجاه ضعف الربط الداخلي، أرقام العناوين/O descriptions)، وبعضها **انكشف كخطأ تصنيف أو عدم قابلية لإعادة الإنتاج** (لا توجد صفحات منتجات أصلًا، ولا مقالات بلا Article Schema، ولا أخطاء JS/CSS، ولا 5,001 خطأ Schema — التفصيل الكامل في `04-ahrefs-comparison.md`)، وبعضها **كان أقل من الحقيقة بمراحل** لأن الزحف المجاني في Ahrefs غطى عينة صغيرة (noindex الحقيقي ~6,367 صفحة لا 175؛ والمفهرس خارج Sitemap ~11,160 لا 906).

## خارطة القرار التنفيذية (التفصيل في `06-remediation-plan.md`)

- **P0 فوري:** أفعال المالك في GSC (URL Inspection للصفحات التجارية + تصدير Coverage طازج) — القناة الوحيدة نحو Google · إصلاح 3 روابط داخلية مكسورة (404) · إصلاح خطوة نشر المقالة الفاشلة.
- **P1 هذا الأسبوع (كود/محتوى بعد موافقة المالك):** حسم قرار ذيل USDA المعلق (D-2) لإيقاف استنزاف الزحف · إثراء التمارين الرقيقة (730/868 EN) · تجربة P0-A لتفرد خلايا الخطط (جاهزة للمراجعة) · ItemList على 12 صفحة · وصل المقالة اليتيمة.
- **P2 لاحقًا:** بناء السلطة (محرك الروابط white-hat الجاهز + قنوات P1-9) · مراقبة أسبوعية · تحسينات ثانوية (عناوين طويلة، ترويسات، إتاحة).

**التنبيه الصادق:** لا يوجد إصلاح كودي واحد يعيد الفهرسة تلقائيًا — القيود الحاكمة هي سلطة النطاق وقرار تقييم Google؛ الخطة تزيل العقبات المقيسة وتفتح قناة إعادة التقييم، والتعافي الزمني خارج سيطرة أي طرف.
