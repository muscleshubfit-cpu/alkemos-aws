# 07 — الفحوص التي تعذر تنفيذها وسبب تعذرها (حدود القياس الصادقة)

| # | الفحص المتعذر | السبب المحدد | البديل المستخدم / المسار المتاح |
|---|---|---|---|
| 1 | **Google Rich Results Test** (التحقق من ادعاء Ahrefs: «خطآن») | أداة Google التفاعلية (search.google.com/test/rich-results) بلا واجهة برمجية عامة مجانية، وتشغيلها يتطلب متصفحًا ووصولًا يدويًا | تحقق JSON-LD برمجي كامل (صفر أخطاء تحليل + تغطية الأنواع الإلزامية 100% عدا ItemList الـ12 الموثقة) — يغطي معظم ما تقيسه الأداة دون درجة Google السرية |
| 2 | **الوصول المباشر إلى GSC** (Manual Actions · Security Issues · تصدير Coverage طازج · Crawl Stats حي · فحص حالة URL) | لا تتوفر للجلسة اعتمادات GOOGLE_SEARCH_CONSOLE_CREDENTIALS (سر بيئة المالك)، وتقرير Page Indexing غير متاح عبر API أصلًا (حد موثق منذ 10-18) | بيانات GSC الموثقة في تحقيقات المستودع السبعة (مصادقة المالك وواجهته، حتى 11-08/11-10): لا Manual Actions ولا Security Issues · Crawl Stats 18,034 طلبًا 98%×200 · فئات Coverage بتاريخ 10-12 — مع توصية P0-1 بتصدير طازج |
| 3 | **فهرس روابط Ahrefs الخلفي الكامل** (الروابط الخلفية الحقيقية بكل أنكوراتها) | يتطلب اشتراكًا مدفوعًا؛ الخطة المجانية لا تكشف فهرس الروابط عبر API | بحث حر متعدد المحركات + GitHub API + فحص المقتنيات والمجتمعات + جرد المستودع الموثق (5–20 نطاقًا) — التوصية: قراءة واحدة من واجهة المالك في AWT (Links report) لسد الفجوة |
| 4 | **زحف كل صفحة من ذيل الـ17,502+** (تغطية 100% لكل صفحة تفصيلية) | التوازن بين الشمولية وحدود الأدب مع الإنتاج (الزحف الكامل يتطلب عشرات آلاف الطلبات الإضافية فوق الـ~30 ألف طلب منفذة) | زحف 13,800 رابطًا (يغطي 100% من الخريطة وكل العائلات بعينات عميقة) + **تعداد حتمي كامل** لكل روابط الذيل عبر صفحات الترقيم (972 طلب ترقيم) + قاعدة تصنيف noindex متحققة 100% (1,155/1,155) — الأعداد الكلية دقيقة، والقياس الصفحي ممثل |
| 5 | **استرجاع محتوى لقطات Wayback 2012–2014** (تاريخ النطاق السابق) | شبكة الجلسة تحجب جلب محتوى web.archive.org الخام (واجهة التوفر API أجابت: أقرب لقطة 2013-04-10 بحالة 200، لكن المحتوى نفسه غير قابل للجلب) | توثيق وجود التاريخ السابق نفسه (لقطة 2013 + ظهور النطاق في قائمة نطاقات منتهية 2013) — لا دليل سبام؛ يُرصد فقط. المالك يمكنه فتح الرابط من متصفحه: web.archive.org/web/20130410001334/http://alkemos.com |
| 6 | **تشغيل Lighthouse/CWV مختبريًا** | يتطلب Chrome/Puppeteer داخل بيئة الجلسة؛ والقيمة المضافة محدودة لوجود قياسين أقوى | زمن استجابة SiteOne لكل رابط (متوسط 271ms/p90 305ms على 13,800) + تقارير PSI الموثقة سابقًا (SEO-P1-PSI-AFTER + مصفوفة 452 «بعد» 20 جريانًا: BP 100/77 وديسكتوب 98–100) |
| 7 | **مقارنة DOM المُصيَّر بعد تنفيذ JS مقابل HTML الخام** (كل القوالب) | SSR أثبت بالقياس المزدوج (تطابق بايتات Googlebot/Chrome + محتوى كامل في الخام من أول بايت + صفر أخطاء تحميل أصول) أن الطبقة المعروضة والخام متطابقتان بنيويًا؛ وقياسات المستودع السابقة (452: صفر أخطاء console عبر 20 جريانًا) حاضرة | تطابق البايتات على 7 مسارات × 5 عائلات + سلامة كل أصول JS/CSS — يغلق سؤال «هل يرى Google شيئًا مختلفًا» إغلاقًا عمليًا |
| 8 | **Bing Webmaster Tools / IndexNow سجل الإرسال** | الوصول بيد المالك فقط | توثيق سير bing-url-submission الأخضر في سجلات التنفيذ + ادعاء Ahrefs (3,250 غير مرسلة) موسوم «غير قابل للتحقق» — يُقفل بقراءة سير العمل عند المالك |
| 9 | **استعلامات بيانات Supabase الإنتاجية** (تطابق أعداد الصفحات مع الجداول) | تدقيق فقط بلا مساس بالإنتاج؛ والقياس الخارجي الحي (زحف + تعداد) يكفي لأغراض الفهرسة | أعداد التعداد الحي (8,831/2,489/6,342) تطابق توثيق المستودع الداخلي (8,830/2,409/6,341) — تقاطع مصدرين مستقلين |
| 10 | **فحص حجب من داخل شبكات Google الفعلية (AS15169)** | لا يمكن انتحال Googlebot حقيقيًا (تحقق DNS عكسي)، وأي اختبار من خارج Google يبقى قريبًا لا مطابقًا | دليلان بديلان قويان: تحقق CF API قراءة-فقط (نافذة أحداث 14 يومًا موثقة: صفر حجب من نطاقات Google) + Crawl Stats الموثق (18,034 طلبًا 98%×200 — Googlebot الحقيقي يزحف بلا مشاكل) |

> **ملاحظة حدود عامة:** القياسات المستقلة في هذا التدقيق أُجريت في نافذة 2026-11-10/11 على الإنتاج الحي؛ الادعاءات الزمنية (تغير المحتوى بين 06-10 و10-11 مثلًا) تظل خارج قدرة أي قياس لحظي وتحتاج قواعد بيانات الأطراف (Ahrefs/GSC).
