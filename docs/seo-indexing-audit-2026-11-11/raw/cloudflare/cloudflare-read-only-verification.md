# تحقق قراءة-فقط من إعدادات Cloudflare (2026-11-10/11)

> **المنهجية:** استدعاءات API للقراءة فقط (`GET` حصرًا) عبر توكن مالك مُفعّل تم التحقق منه أولًا (`/user/tokens/verify` = valid & active). **صفر تعديلات** — هذا توثيق تدقيق لا تدخل تشغيلي.

## 1. حالة التوكن والنطاق

- التوكن: نشط ومُتحقق منه (`status: active`).
- النطاق المتاح: `alkemos.com` — الحالة: `active`.

## 2. Bot Management (إدارة البوتات) — كل الحمايات معطلة

| الإعداد | القيمة المقروءة | الدلالة لزواحف البحث |
|---|---|---|
| `fight_mode` | **false** | وضع القتال مع البوتات معطل — لا تحدي/حجب للزواحف |
| `ai_bots_protection` | **disabled** | لا حجب لروبوتات الذكاء الاصطناعي |
| `crawler_protection` | **disabled** | لا حماية ضد الزواحف مفعلة |
| `ai_training` / `ai_search` / `ai_user` | **disabled** ×3 | قنوات AI كلها مفتوحة |
| وكلاء AI (Anthropic/Google/…) | **disabled** | لا استثناءات حاجبة |
| `enable_js` | false | لا يُفرض تنفيذ JS على الزوار/الزواحف |

## 3. مستوى الأمان وقواعد WAF المخصصة

- `security_level`: **medium** (الوضع الافتراضي المتوازن).
- قاعدتا WAF المخصستان الوحيدتان النشطتان:

| القاعدة | الإجراء | الوصف | أثرها على محركات البحث |
|---|---|---|---|
| SOCIAL-OG-2 | **skip** | تخطي الحمايات لزواحف المشاركة الاجتماعية الموثقة (FB/WhatsApp/X/LinkedIn/Telegram) | لا شيء (تسهيل لا حجب) |
| BLOCKLIST-1 (مفعلة منذ 2026-10-03) | **block** | حجب أنماط مسارات ماسحات الثغرات/الاستغلال | لا شيء — قائمة أنماط مسارات هجومية لا تطابق زحف HTML لمحركات البحث (مثبت بالقياس: 27 استجابة 200 متطابقة عبر Googlebot/Bingbot/GPTBot/ClaudeBot/PerplexityBot + تطابق بايتات كامل) |

- قيود المعدل (Rate Limits): لا توجد قيود على صفحات HTML (نقطة النهاية لم تُرجع أي قاعدة).

## 4. الخلاصة

**لا يوجد أي إعداد في Cloudflare يحجب أو يُبطئ أو يتحدى Googlebot أو Bingbot أو روبوتات الذكاء الاصطناعي.** هذا يطابق ويؤكد بشكل مستقل ما وثقه التحقيق السابع (نافذة أحداث الجدار 14 يومًا: صفر حجب من AS15169 ونطاقات Google — SEO-CNI-SELECTION-ANATOMY-2026-11-10 §3) وينفي فرضية «حجب البوتات بعد الانتقال إلى AWS» نفيًا مزدوج الأدلة.
