# GSC API capabilities — الحقائق المؤكدة بمصادرها (أعيد التحقق 2026-11-12)

> **الغرض:** جزء «قدرات GSC» من إعادة التدقيق الإلزامية — ما يستطيعه حساب الخدمة القائم (نطاق `webmasters.readonly`) فعله عبر API، وما لا يستطيعه إطلاقًا.

## 1. URL Inspection API — ضمن النطاق القائم، قراءة-فقط

| الحقيقة | المصدر |
|---|---|
| الطريقة: `urlInspection.index.inspect` (POST `https://searchconsole.googleapis.com/v1/urlInspection/index:inspect`) | مرجع Search Console API الرسمي |
| **نطاقات التفويض المقبولة: `webmasters` أو `webmasters.readonly`** — أي أن حساب الخدمة القائم بنطاقه الحالي **مؤهل بلا أي تغيير نطاق** | مرجع الطريقة الرسمي (Authorization Scopes) |
| الحصة لكل موقع: **2,000 استعلام/يوم · 600/دقيقة** (لكل مشروع: 10M/يوم · 15k/دقيقة) | صفحة Usage Limits الرسمية |
| **قراءة-فقط**: لا «طلب فهرسة» عبر API إطلاقًا — «Request indexing» واجهة GSC البشرية حصرًا | توثيق Google (والواقع القائم: القناة اليدوية وحدها) |
| أثرها على A1 (الـ25 تجارية غير متحققة): 25 استعلامًا ≪ 2,000/يوم — السعة كافية بأضعاف | حساب مباشر من الحصة الموثقة |

**مصادر URL:**
- `https://developers.google.com/webmaster-tools/v1/urlInspection.index/inspect`
- `https://developers.google.com/webmaster-tools/limits`

## 2. Search Analytics API — مثبت حيًا بالفعل (وهو ما يشغّله سير عمل الاختبار)

| الحقيقة | المصدر |
|---|---|
| `searchAnalytics.query` — يردّ الظهور/النقرات/الموضع بالتجميعات والأبعاد | مرجع API |
| الحصة: لكل موقع 1,200/دقيقة · لكل مشروع 30M/يوم + 40k/دقيقة + حصص حملة (10 دقائق/يوم — التجميع بصفحة×استعلام معًا هو الأغلى) | صفحة Usage Limits الرسمية |
| مثبت حيًا من تشغيلات سير عمل الاختبار (نافذة 28 يومًا، dataState=final، 3 استعلامات لكل خاصية) | تشغيلات 10-10→10-11 (الخام `connection-test-runs.json`) |

## 3. ما ليس متاحًا عبر API (حدود صادقة — سبب القنوات اليدوية القائمة)

- **تقرير «فهرسة الصفحات» (Coverage) لا يُقرأ عبر API** — قناته الوحيدة التصدير اليدوي من واجهة GSC — وهذا هو سبب التصديرات اليدوية التي عملت عليها التقارير 11/13/16 (Coverage zips).
- **طلب الفهرسة (Request indexing)** — واجهة فقط، لا API.
- لافتة أن تصدير GSC **بلا مصفوفة صفحة×استعلام** (ملفا Pages/Queries منفصلان) — قيد موثق سابقًا بالتقرير 17 §6 ويظل قائمًا.

## 4. الاستنتاج الحاكم للقدرات

حساب الخدمة القائم بنطاقه **يستطيع اليوم** (بلا أي تغيير): قراءة Search Analytics (مثبت حيًا) **+** فحص URL قراءة-فقط عبر URL Inspection (النطاق مؤهل والحصة كافية لوظيفة مثل A1 بأضعاف). **لا يستطيع:** طلب فهرسة، ولا قراءة تقرير Coverage آليًا. أي بناء فوق هذه القدرات = «تنفيذ GSC» بالمعنى المقيد بأمر 2026-09-30 → محظور داخل نافذة 2026-10-30→2026-11-29 ويُفتح بأمر مالك من إغلاق النافذة (2026-11-30 فصاعدًا).
