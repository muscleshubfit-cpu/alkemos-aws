## 5) مقترحات الإصلاح

- **P0 (منفذ — هذا الكوميت):** بحث خارجي حقيقي عبر `googleSearch` grounding داخل المهايئ الأصلي وحده (قانون حظر استدعاء المستهلكين للـ API قائم)؛ أدلة البحث (webSearchQueries + groundingChunks: uri/title) تُخزَّن في `research0` (searchedQueries/sources) وتدخل P1 (researchDigest) وP2 (VERIFIED SEARCH CONTEXT)؛ **إزالة البدائل**: مسار السلسلة-بدل-البحث ومسار curated-fallback أُزالا من التشغيل — الفشل صادق (500 → إعادة العدّاء ×3 → أحمر واضح بدل نشر «بحث» مزيف). بوابة صادقة إضافية: رد 200 بلا أدلة grounding يُرفض («النموذج أجاب من الذاكرة») — لا يمكن لذاكرة النموذج انتحال البحث.
- **P1 (منفذ — هذا الكوميت):** تبديل الافتراضي إلى `gemini-3.5-flash` (نفس طبقة flash، إصدار مستقر أسبق، أقل ازدحامًا على المجاني، نفس شكل الـ API) — في الـ registry والسلسلتين وسطر اللوج، مع بقاء GEMINI_MODEL كمقبض بلا نشر وبقاء قانون GEMINI-FIRST حرفيًا.
- **مؤجل (خارج نطاق الأمر — §7):** عتبة الإجابات القصيرة في EVO · empty-retry فوري لمداخل gemini · توصيل GEMINI_MODEL في workflows · جودة طول P2 · المراقبة عبر التقرير الأسبوعي (أول تقرير آلي 2026-10-12).

## 6) خطة التنفيذ المختصرة (كما نُفذت بالكوميت نفسه)

1. **`ai-provider.ts`** (السطح الوحيد المسموح بالكود الأصلي): إضافة خيار `googleSearch` إلى `CallAIOptions` · `geminiBuildBody` يضيف `tools:[{googleSearch:{}}]` **ويكبح** `responseMimeType` (واجهة REST ترفض JSON-mode مع الأدوات — نمط حارس Groq 177: تعليمات STRICT-JSON بالموجّه + parseJSON المتسامح) · استخراج/تطبيع `groundingMetadata` (استعلامات ≤10 + صفحات ≤12 مُزالة التكرار) · **بوابة الرد غير المُرسَّى**: 200 بلا أدلة = خطأ صادق يُحسب isEmpty · `callGeminiGenerate` صار يُرجع `{text, grounding}` (فرع callAI يفكّ النص فقط — عقده القائم بلا تغيير) · دالة مُصدَّرة جديدة `callGeminiGroundedSearch` (تفتش GEMINI_MODEL ثم الافتراضي، ترفض غياب المفتاح برسالة «لا بديل مسموح») · تبديل الافتراضي إلى `gemini-3.5-flash` في الـ registry والسلسلتين وسطر اللوج.
2. **`blog-research.ts`:** `researchLanguage` تستدعي النداء المُرسَّى مباشرة (بوسم `blog:research` نفسه لاستمرارية العدّادات) · prompt يعمل بموجّه «استخدم أداة بحث Google» بدل «معرفتك التدريبية» · الصيغة JSON نفسها (keywords/faqs/topics) فلا يتغير أي مستهلك · إرفاق الأدلة الحية من groundingMetadata حصريًا (لا يركب صدى النموذج) · **حذف مساري البديل**: لا `callFreeAIFallbackChain` ولا عودة `curated-fallback` — الخطأ ينتشر صادقًا · `fallbackResearch` باقية **كـ test fixture فقط** (تستوردها 5 ملفات اختبار) · `researchUsedFallback` باقٍ ككاشف تراثي للصفوف القديمة.
3. **`blog-pipeline.ts`:** `researchDigest` يضيف سطري «LIVE SEARCH QUERIES» + «TOP LIVE SEARCH RESULTS» (P1) · `generateFullArticle` يضيف كتلة «VERIFIED SEARCH CONTEXT» (P2) — **فارغة للصفوف التراثية = مطابقة بايت-بالبايت للسلوك السابق** · قانون الاقتباس FACT GUARD لم يُمس (النطاق: تغذية النتائج، لا إعادة كتابة قواعد الاقتباس).
4. **الحوكمة:** `.env.example` (تعليق GEMINI_MODEL) · كاناري 344 (13 اختبارًا جديدًا في `ai-provider-gemini.test.ts` + `blog-research-grounding.test.ts` بنمط تثبيت المصدر القائم) · تحديث pins النموذج في الاختبارين · هذا التقرير + صف السجل + STATE 344 + worklog.
5. **الاختبار (الحد الأدنى، بلا تشغيل مدونة ولا استهلاك Vercel):** `tsc --noEmit` = صفر · vitest كاملًا محليًا = **2,306/2,306** (منها 9 ملفات المعنية بالسطح المُعدَّل) · بوابات docs المحلية — لا dispatch لأي workflow ولا نداء إنتاج إضافي.
