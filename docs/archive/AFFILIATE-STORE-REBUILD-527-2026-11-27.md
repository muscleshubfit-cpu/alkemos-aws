## §2 — التغييرات المنفذة

### §2.1 527-L1 — إعادة بناء طبقة البيانات (حظر الـembed)

`src/lib/affiliate-store-server.ts` أُعيدت كتابته بالكامل حول **لقطة واحدة مُكاشة** (`getAffiliateStoreSnapshot`): قراءة مباشرة للفئات النشطة + قراءة مباشرة للمنتجات المنشورة + ربط برمجي (خريطة id→فئة وخريطة فرع→أصل) — **صفر استعلامات embed**. كل الواجهات العامة تشتق منها: الشجرة، الفئات المؤهلة، البطاقات، صفحة التصنيف، صفحة المنتج، الأسطح، وخريطة الموقع (مع تخطي المنتجات بلا فئة ورقة فلا يتكرر عطل الشرطة المزدوجة بنيويًا).

### §2.2 527-L2 — النشر التلقائي (إلغاء الاعتماد المزدوج)

- `affiliate-store-admin.ts`: الإنشاء **يولد منشورًا** (`is_published: true` فور الحفظ الناجح)؛ تعديل منتج منشور يبقيه منشورًا («وأي تعديل وحفظ لمنتج منشور ينعكس تلقائيًا»)؛ `review_status` يُكتب `reviewed` كسجل تاريخي فقط؛ حذف دالة المراجعة `adminReviewAffiliateStoreProduct` بالكامل وشرط `review_status` من النشر؛ كل حفظ يflush الكاش الثلاثي (tags + paths + Cloudflare edge) فورًا.
- `api/admin/affiliate-store/route.ts`: حذف إجراء `review`؛ المجموعة: publish (إعادة نشر) · unpublish (إخفاء) · feature · category-activate.
- `AffiliateStoreAdminView.tsx` أعيد بناؤها: لا صندوق مراجعة ولا زري Mark reviewed/Publish — قائمة منتجات بصور مصغرة حقيقية + إحصاءات (Total/Live/Featured/بلا صورة-ASIN) + تنبيه 527-G2 للمنتجات الناقصة + Unpublish/Republish وFeature وتفعيل الفئات كما هي.
- `AffiliateStoreEditorView.tsx`: نصوص الحفظ = «حُفظ ونُشر فورًا»، حقل الصورة يعكس القانون الجديد (إلزامي + المصدر الموثوق CDN أمازون)، المعاينة الحية بنفس المكونات العامة الجديدة.

### §2.3 527-G1 — الصور الأصلية من المصدر الموثوق (تعديل حارس الصورة)

- الحارس القديم كان يحظر كل نطاقات صور أمازون (clause h). **بأمر المالك 527** («استخدام صور المنتجات الأصلية من مصادر موثوقة ومسموح باستخدامها» + «عرض صورة المنتج الفعلية في كل بطاقة وكل صفحة تفاصيل»): أصبح المصدر الموثوق المسموح هو **CDN صور أمازون الرسمي `m.media-amazon.com`** (الصورة الأصلية للإدراج نفسه الذي يشير إليه المتجر — الصورة التي يعرضها برنامج الشركاء للإدراج) + أصول alkemos.com المستضافة ذاتيًا؛ بقية النطاقات (بما فيها نطاقات أمازون الأخرى: ssl-images/ecx/images-amazon وصفحات amazon.*) تبقى محظورة.
- قوانين الأشخاص بلا مساس: حظر النساء/الفتيات مطلق (§0.1) وحظر العري/الكاشح للرجال (§0.2) — بفحص نصي URL/alt عند الكتابة.
- `AffiliateStoreProductImage`: عند فشل تحميل الصورة يظهر **بديل احترافي محايد** بعلامة «Image unavailable» واضحة — **لا يُقدَّم باعتباره صورة المنتج** أبدًا (لا أيقونة فئة متنكرة).

### §2.4 527-G2 — بوابة الرف (الصورة + رابط الشراء إلزاميان)

حارسان جديدان حاجبان في `runAffiliateStoreProductGuards`: `shelf-image-required` (بلا image_url لا نشر) و`shelf-buy-link-required` (بلا ASIN صالح لا نشر) — لأن النشر صار تلقائيًا فالحرس الآلي هو البوابة الوحيدة («لا تسمح بالنشر إلا بعد اجتياز التحقق الآلي من البيانات الأساسية والصورة ورابط الشراء، دون تدخل يدوي»). طبقة القراءة العامة تُطبق نفس الشرط (`isShelfProduct`) فلا يظهر منتج ناقص بأي سطح عام حتى لو تسربت حالته.

### §2.5 527-D1 — إعادة التصميم التجارية الكاملة

- **البطاقة الجديدة** (`AffiliateStoreProductCard`): عمودية بصورة مربعة كبيرة أعلاها (نسبة aspect-square) + شارة Featured على زاوية الصورة + العلامة + العنوان (سطران) + الملخص + سطر السعر (`See price on Amazon` ما لم يوجد سعر API موثوق — لا اختراع أسعار) + درجة التحرير + زر **View Product** واضح أسفل البطاقة.
- **صفحة المتجر** (`/affiliate-store`): ترويسة تجارية (اسم المتجر + وصف + إفصاح د-2) + **بحث** (عبر q) + **فلترة** (تصنيف + علامة تجارية) + **ترتيب** (Featured/الأحدث/الأعلى تقييمًا/السعر تصاعديًا وتنازليًا/الاسم — فرز السعر يعمل عند توفر أسعار API) + بلاطات تصنيفات بصرية + **شبكة كاملة بكل المنتجات المؤهلة** (ليست المميزة فقط).
- **صفحة التصنيف**: ترويسة بالأيقونة والوصف + رقائق تصنيفات فرعية بعدّادات + **الشبكة الكاملة لكل منتجات الشجرة** (إصلاح الفراغ) + قسم «Continue browsing» لبقية الفئات.
- **صفحة المنتج**: عمودان (صورة كبيرة + عمود الشراء: العلامة/العنوان/الدرجة/الملخص/سطر السعر/وحدة الشراء الكبيرة «See price on Amazon» بإفصاح م-1 ملاصق/مواصفات: الفئة والقسم والعلامة وتاريخ المراجعة) + المحتوى التحريري + مشاركة + منتجات ذات صلة من نفس الفئة الرئيسية.
- زر الشراء الكبير (`AmazonBuyButton variant="large"`) + توحيد CTA على «See price on Amazon» (صياغة المالك).
- **قسم الرئيسية** (LandingView): مدخل تجاري حقيقي — «The store behind the training» + 4 بطاقات منتجات فعلية بصورها الحقيقية + رقائق الفئات المؤهلة (روابط فقط — لا رقائق ميتة) + CTA «Shop the store».
- **أشرطة المحتوى** (SurfaceRail/SuggestStrip): بنفس البطاقات الجديدة وشبكة تجارية.

### §2.6 بيانات الإنتاج — الصور والـASIN الموثقة (27/27)

جُمعت البيانات من صفحات أمازون الحية عبر متصفح حقيقي (لا اختراع — كل ASIN شوهد فعليًا في رابط amazon.com/.../dp/ASIN وتطابق العنوان والمنتج):

- **11 منتجًا** كان ASINها موجودًا: تحقق + صورة أصلية عالية الدقة (`data-old-hires` ‏SL1500).
- **16 منتجًا** بلا ASIN: عُثر على الإدراج الحقيقي (بحث موجه + فتح الصفحة والتحقق من العنوان) — منها Metcon 9 (B0DX7H6HW5 — استُبعدت نتائج Metcon 8/10 الخادعة) وSunny SF-RW5515 (B09Y9H42CH — تأكيد البحث المباشر «SF-RW5515») وRenpho gun (B085NTR26K) وWalkingPad A1 Pro (B08WTMLGXF).
- **الفحص البصري الآلي لكل صورة (27/27)** عبر نموذج رؤية: PEOPLE=none · IMMODEST=no · SUBJECT=product-only · MATCH=yes — **استُبعدت صورتان** تحويان نساءً (الصورة الرئيسية لآلة التجديف Sunny + بديلة) واستُبدلت بصورة معرض مطابقة خالية من الأشخاص (41ASrzCESlL) — تحققًا للقانون المطلق.
- كل الروابط الـ27 فُحصت HTTP (200 image/jpeg) قبل الإدخال.
- طُبقت على قاعدة الإنتاج عبر REST (سكربت `scripts/apply_product_media.py` خارج المستودع — لا يُشحن بالكود): **27/27 بصورة وASIN، 27/27 مؤهلة للرف (صورة+ASIN+منشورة)**.
