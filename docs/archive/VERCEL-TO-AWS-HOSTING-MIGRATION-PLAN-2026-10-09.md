## النتيجة النهائية — طوبولوجيا الإنتاج الحالية
- **الحوسبة:** AWS Lightsail بمنطقة **eu-north-1 (ستوكهولم)** — باقة $7/ش `micro_3_0` (‏2 vCPU/1GB RAM/40GB SSD/2TB نقل) + IP ثابت.
- **نظام التشغيل والتشغيل:** Ubuntu 24.04 · Node 22 LTS + PM2 + `next start` (بلا Docker وبلا `output: standalone`) · swap ‏2GB + `vm.swappiness=10`.
- **قياس الذاكرة المبرر للباقة:** RSS ‏209–262MB بعد التسخين وذروة 356MB بعد 3 توليدات OG متتالية (Satori+Harfbuzz عربي) — معيار «RAM مقيس <700MB» محقق؛ `ecosystem.config.js`: ‏`max_memory_restart` ‏600M + `--max-old-space-size=512`.
- **خط النشر:** `.github/workflows/deploy-aws.yml` — بناء في GitHub Actions (bun 1.3.14 frozen + Node 22، نفس بيئة quality-gate) → نقل `.next`+`public`+`bun.lock` عبر SSH إلى `/srv/alkemos/releases/<sha>` → تفعيل ذري (symlink) عبر `deploy/deploy.sh`.
- **أمان النشر:** فحص صحة `/api/build-info` بعد التفعيل **وتراجع آلي** للإصدار السابق عند الفشل؛ تراجع يدوي `deploy/rollback.sh`؛ Preflight يفشل مبكرًا عند غياب الأسرار؛ `permissions: contents: read` + `concurrency` مصطف.
- **التحقق الآلي بعد كل نشر:** فحوص خادم عبر SSH + بطارية حافة من العدّاء عبر `--resolve` بشهادة Caddy الداخلية (ثنائية اللغة، الدخول، الهيدرز السبعة، تكافؤ الكاش، og-image عربي، مجس SSE، التحويلات) + مدخل `rollback_drill` اختياري.
- **HTTPS:** Caddy (شهادة Let's Encrypt تلقائيًا خلف بروكسي Cloudflare، SSL ‏Full-strict؛ البديل عند التعارض: Cloudflare Origin CA) — `deploy/Caddyfile` يحمل حرفيًا هيدرز الأمان السبعة من `vercel.json` + قواعد Cache-Control للصور بقانون `defer` (مقيس على Caddy 2.8: بدونه هيدران مزدوجان على السلك).
- **الأسرار:** تُدار من GitHub Secrets حصرًا (`AWS_DEPLOY_HOST/USER/SSH_KEY`) وتُرحَّل آليًا إلى `/srv/alkemos/shared/.env` (دمج idempotent؛ 16 مفتاحًا اختياريًا؛ القيم لا تُطبع بأي سجل) — لا تحرير يدوي على الخادم؛ مفتاح النشر يُولَّد خارج الخادم (عامه عبر `setup-server.sh --deploy-key` وخاصه في Secret حصرًا).
- **الجدولة:** crontab الخادم `deploy/crontab-alkemos` يحل محل Vercel crons بنفس الجداول حرفيًا (`progress-reminder` الأحد 07:00 · `dispatch-pipelines` يوميًا 23:40 UTC) بنداء `127.0.0.1:3000` مع `Bearer CRON_SECRET` — صفر تغيير كود.
- **التراجع:** `vercel.json` **أصل مجمّد للتراجع بDNS فقط** — مشروع Vercel ظل يبني مع كل push طوال الازدواج (قانون `[vercel skip]` للتوثيق فقط)؛ التراجع = إعادة سجل A/AAAA في Cloudflare (5–15 دقيقة بعد خفض TTL إلى 300) بلا أي لمسة كود أو بيانات.
- **Cloudflare بلا تغيير سوى عنوان الأصل وقت القطع:** DNS على زون Free ببروكسي أمامي وكاش HTML الرسمي (قاعدة `alkemos cache rules` + RSC bypass — أربع قواعد حية)؛ شهادة الأصل Let's Encrypt عبر HTTP-01 تعمل خلف البروكسي بوضع SSL ‏Full-strict الحالي.
- **النسخ الاحتياطي لا يتغير إطلاقًا:** DB يومي 05:30 UTC إلى ريبو خاص · Storage إلى GDrive خارجي · دريلات استعادة — كلها من GitHub Actions ومستقلة عن الاستضافة؛ الخادم عديم الحالة (نسخته = Git + ‏`.env` + سكربتات + لقطة أسبوعية).
- **المراقبة:** `pm2 monit` + سجلات مُدارة · فحص خارجي على `/api/build-info` (منارة النشر) · مقاييس Lightsail الأساسية المجانية · AWS Budget كحارس Bill Shock — لا CloudWatch مدفوع.
- **سير العمل:** 28 من الـ30 مستقلة عن الاستضافة (تعمل على runners وتضرب Supabase/AI مباشرة) — لم يتغير منها شيء؛ `vercel-cleanup.yml` ظل يعمل خلال الازدواج؛ اعتمادات Vercel الفعلية في الكود ثلاث فقط (`@vercel/analytics` no-op · ‏`VERCEL_GIT_*` بfallback · ‏`vercel.json`).
- **التوافق مقيسًا قبل النقل:** بناء 94 ثانية بوضع demo · 2,102 صفحة demo (2,294 بالمتغيرات الحقيقية) · مسار og-image الوحيد يعمل على Node · `/_next/image` ميت 410 (قانون `unoptimized: true`).

## القرارات والقوانين المعمارية الناتجة
- **المنطقة eu-north-1 قيدًا دائمًا:** SCP للتجربة يرفض أي موارد إقليمية خارجها (explicitDeny مقيس)؛ Supabase يبقى eu-central-1 (+20–30ms مقيس لكل جولة DB غير مخزنة) — المجرى الرسمي لفرانكفورت استُبعد بأمر المالك.
- **Node+PM2 بلا Docker قانونًا:** التطبيق عديم الحالة (صفر كتابات FS مقيس) وكل حمل AI يعمل on-runners في Actions — الخادم خادم ويب خفيف (~0.2 req/s بعد ISR)؛ Docker يرفع التعقيد بصفر منفعة.
- **كل التغييرات إضافية additive:** `src/**` و`next.config.ts` و`vercel.json` و`supabase/**` وكل workflows القائمة لم تُمس؛ لا migration ولا تغيير RLS.
- **الأرصدة:** $100.00 حتى **2027-04-09** (مقيس freetier get-account-plan-state؛ الحساب فُتح 2026-08-06) — ‏$0 نقدًا خلال النافذة (6×$7=$42 مغطاة) ثم $7/ش ثابتة شاملة.
- **قانون Caddy:** قاعدة `/_next/image` لا تُنسخ عمدًا (المسار ميت 410)؛ هيدرز HTML مصدرها `next.config.ts` ‏(SEO-GEO-4) وتعمل من الأصل مقيسًا — بلا لمس.
- **وضعا Caddy:** `deploy/Caddyfile` للقطع (Let's Encrypt تلقائي) و`deploy/Caddyfile.test` للاختبار (`tls internal` بلا DNS بنفس القواعد) — `caddy validate` قبل التركيب.
- **مسار التنفيذ الموثق (المراحل 0→6):** تحقق المالك → تجهيز الخادم (`deploy/setup-server.sh` بوضعي `--test`/الإنتاج) → ملفات التطبيق → خط النشر → بطارية التحقق قبل أي DNS (لا يُتجاوز الباب إلا باخضرار كل بند) → القطع بمراقبة 48 ساعة → ما بعد الاستقرار.
