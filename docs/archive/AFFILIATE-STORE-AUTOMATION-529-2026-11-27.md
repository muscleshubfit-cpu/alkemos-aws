## 1. الحقيقة الحاكمة: الواجهة الرسمية (متطلب خارجي موثق بصدق)

**أمازون أوقفت PA-API 5.0 نهائيًا في 2026-05-15** (المصدر: دليل الترحيل الرسمي — affiliate-program.amazon.com/creatorsapi/docs). الواجهة الرسمية الوحيدة الآن لبيانات منتجات Associates هي **Amazon Creators API**:

| البند | القيمة الرسمية |
|---|---|
| القاعدة | `https://creatorsapi.amazon/catalog/v1/{searchItems,getItems}` |
| المصادقة | OAuth 2.0 `client_credentials` (Credential ID + Secret → bearer صالح ساعة، قابل للكاش) |
| نقطة التوكن (NA) | `https://api.amazon.com/auth/o2/token` (نطاق `creatorsapi::default`) |
| الترويسات | `Authorization: Bearer …` · `Content-Type: application/json` · `x-marketplace: www.amazon.com` |
| الموارد المستخدمة | `images.primary.large` · `itemInfo.title` · `itemInfo.features` · `itemInfo.byLineInfo` · `offersV2.listings.price` · `offersV2.listings.availability` · `parentASIN` |
| الأهلية | **10 مبيعات مؤهلة خلال آخر 30 يومًا + تسجيل الوصول من Associates Central (Tools → Creators API)** |

**المتطلب الخارجي على المالك (غير متوفر حاليًا — موثق بأمانة):** إصدار Credential ID/Secret بعد استيفاء الأهلية وإضافتهما كسرّي مستودع: `AMAZON_CREATORS_API_CREDENTIAL_ID` و`AMAZON_CREATORS_API_SECRET` (يزرعهما deploy-aws.yml env-sync تلقائيًا). **حتى ذلك الحين تعمل المنظومة بوضع الخمول الصادق** (نمط EXCHANGERATE_API_KEY): كل تشغيلة تُسجَّل صف فشل بسبب `missing-credentials`، **بلا أي بيانات وهمية أو جلب مزيف أو واجهات شكلية** — وهذا هو الالتزام الحرفي بشرط المالك: «لا تعتبر وجود واجهات شكلية أو مهام مجدولة غير متصلة بمصدر بيانات حقيقي إنجازًا».

## 2. ما بُني (كل مكوّن مربوط بشرط الأمر)

### 2.1 نظام الجلب التلقائي (`affiliate-store-fetch.ts` + `amazon-creators-api.ts`)
- **الواجهة:** عميل Creators API كامل (توكن OAuth2 بكاش ساعة، searchItems/getItems بتقسيم دفعات 10، إعادة محاولة واحدة محدودة على 429 ثم استسلام صادق، أخطاء مصنّفة). لا scraping إطلاقًا.
- **الجلب:** لكل فئة نشطة من `affiliate_store_fetch_categories` (كلمات مفتاحية + هدف) — بحث متسلسل (انضباط المعدل)، منع التكرار بASIN (فحص DB + داخل الدفعة + فهرس فريد من 0115)، فلترة (صورة موجودة + ASIN سليم)، **بوابة الحرّاس الكاملة** (527-G: صورة CDN أمازون + ASIN + قائمة الحجب الحلال + انضباط الادعاءات + إشارات نسائية/عري على العنوان/alt — منتجات الملابس النسائية تُرفض آليًا)، محتوى تحريري EN أصيل مولّد حتميًا (قالب ≥250 كلمة، بلا نسخ أمازون، بلا ادعاءات/نسب/كحول)، ثم الإدراج **بنفس مسار الحفظ المحروس** (قانون النشر التلقائي 527-L2) مع كاش-فلاش ثلاثي الطبقات.
- **المزامنة:** كل ASIN منشور يُعاد فحصه كل تشغيلة (getItems): تحديث payload/السعر (API-served — الصنف المسموح ببند السعر) + price_updated_at + التوافر + الصورة (بمضيف m.media-amazon.com حصرًا) + العنوان؛ **غير المتاح → إخفاء** (is_published=false + ملاحظة توافر — لا حذف أبدًا، قانون السلغ) + تعطيل روابطه الداخلية تلقائيًا (لا روابط ميتة). **المفقود من الكتالوج → إخفاء كذلك.**
- **الجدولة والتحكم:** الدورية (يومي/أسبوعي/شهري) من لوحة الإدارة؛ workflow يومي 07:17 UTC يطلق النقطة والنقطة تقرر التنفيذ بفحص الدورية؛ تشغيل يدوي؛ إيقاف مؤقت (is_enabled=false).
- **منع التداخل:** ثلاثة أقفال — مجموعة concurrency بالworkflow + **فهرس فريد جزئي على status='running' بقاعدة البيانات (0120 — تشغيلتان متزامنتان مستحيلتان بنيويًا)** + فحص الدورية؛ مع حصاد الأقفال الميتة (>ساعتين → failed موثق) فلا يمكن لانهيار عامل أن يجمّد الجدولة.
- **السجل والتنبيهات:** كل تشغيلة بصف كامل (عداد مرشح/مدرج/محدث/مرفوض/مخفي + سجل أحداث jsonb + ملخص خطأ)؛ **التنبيهات:** تشغيل GitHub أحمر (503/502) + إشعار جرس أدمن مقيد بمرة/يوم UTC (dedupe) — الرؤية المزدوجة.

### 2.2 لوحة التحكم (`/admin/affiliate-store/automation`)
قسم مستقل كامل (5 تبويبات): التحكم (تشغيل/إيقاف، دورية، سقف الجلب، عتبة الربط وسقف الروابط/صفحة، تشغيل يدوي، مسح ربط يدوي) · حالة بيانات الاعتماد (**أعلام بوليانية فقط — لا قيم أبدًا**) مع لوحة المتطلب الخارجي بالعربية والإنجليزية · فئات الجلب (كلمات/هدف/تفعيل) · سجل التشغيلات (عدادات + أخطاء) · مقترحات الربط (اعتماد/رفض + الروابط المطبقة بتعطيل/تنشيط) · **التحليلات** (انطباعات/نقرات/CTR/أعلى منتجات/أعلى صفحات/أداء تصنيفات/صفر تفاعل + شريط 14 يومًا). مدخل من لوحة المتجر الرئيسية.

### 2.3 الربط الداخلي الذكي (`affiliate-store-linking.ts`)
- **الصلة الحقيقية (لا تطابق كلمات عشوائي):** خريطة موضوعية فئة↔ألفاظ EN (54 فئة) + تداخل توكنات موزون (عنوان ×3 / عناوين ×2 / متن ×1 ضد عنوان المنتج/ماركته/فئته/ملخصه) + مكافأة عبارة العنوان الكاملة. **القبول يتطلب تطابق فئة أو ≥3 توكنات مميزة ودرجة ≥20**؛ التطبيق الآلي فوق عتبة المالك (30 افتراضيًا، قابلة للضبط).
- **الأسطح (EN حصرًا):** مقالات المدونة (`language='en'` حرفيًا) · الوصفات (النصف EN فقط) · البرامج التدريبية · مكتبة التمارين (إشارة المعدات) · صفحات الأدوات والتغذية والموارد.
- **الإدراج الطبيعي:** `insertStoreLinks` — حقن وقت العرض على قانون insertToolLinks: أول تكرار بحدود كلمات، روابط داخلية لصفحة المنتج (`/affiliate-store/[فئة]/[سلغ]` — لا روابط أمازون مباشرة بالمتن)، idempotent، سقف لكل صفحة، لا داخل روابط/عناوين/جداول قائمة، **no-op صارم لأي لغة غير EN** (كاناري مثبت بالمصدر). **النص المخزن لا يُمس أبدًا.**
- **المقترحات:** طابور `affiliate_store_link_suggestions` (درجة + سبب بالتوكنات المطابقة للتدقيق) — فوق العتبة تُطبق آليًا (روابط inline + رابط شريط التوثيق `affiliate_store_product_links` — إعادة استخدام مسار العرض القائم)، دونها تبقى معلقة لاعتماد الأدمن.
- **التحديث عند الإخفاء:** منتج يُخفى/يُحذف → روابطه deactivate + فلاش كاش (لا روابط ميتة، لا صفحات بلا منتج مناسب مناسب تُجبر على روابط).

### 2.4 قواعد اللغة والفصل (قانون §0 مشددًا)
المتجر EN فقط؛ الروابط الداخلية تظهر بالمحتوى الإنجليزي حصرًا (كاناري مصدري: AR page لا يستورد insertStoreLinks؛ الفحص يستعلم language='en' حرفيًا؛ insertStoreLinks no-op لغير EN). **صفر روابط أفلييت بالمحتوى العربي** (شجرة (ar) نظيفة — كاناري الفحص العكسي). لا خلط مع Site Partners (النظام 1 — كاناري الفصل معمم على كل ملفات 529 الجديدة). المتجر العربي المستقبلي (النظام 3) لم يُقترب: صفر جداول/مسارات/أعمدة عربية.

### 2.5 التتبع والتحليلات
- **الانطباعات:** beacon مجمّع (`/api/affiliate-store/impressions`): مكون IntersectionObserver صغير (مرة/صفحة، دفعات ≤24، صفر PII) → RPC ذري `affiliate_store_track_impressions` (صف يومي لكل منتج×سطح×يوم) على جداول `affiliate_store_impression_events`. مثبت على: المتجر + صفحات الفئات + صفحة المنتج (وبطاقات المنتج تحمل `data-store-product-id`).
- **النقرات:** مسار 0115 القائم دون تغيير.
- **التقارير:** إجماليات + CTR، لكل منتج، لكل سطح/صفحة، لكل تصنيف، أعلى المنتجات والصفحات، **منتجات صفر تفاعل** (≥20 انطباعًا بلا نقرات) — بنوافذ 7/30/90 يومًا من لوحة الإدارة.

### 2.6 الحماية والجودة
الالتزام بالواجهة الرسمية فقط (صفر scraping) · انضباط الطلبات (تسلسل + سقف لكل تشغيلة + 429 بتراجع واحد) · الإفصاح (سطر OA ملاصق لزر الشراء القائم + الروابط الداخلية تحيل لصفحة المنتج حيث يعيش الإفصاح — لا نِسب علنية بالحارس التاسع) · منع الروابط المكسورة (فيريفاي + إخفاء غير المتاح + تعطيل الروابط) · **قفل تداخل المهام بثلاث طبقات** · منع صور النساء/العري (بوابة المفردات على العنوان/alt + فئات الملابس عالية المخاطر تُبذر معطلة — فحص الرؤية العميق يبقى مسار المحرر اليدوي الموثق) · الأداء وSEO (كل العرض server/ISR، صفر JS طرف ثالث جديد عدا جزيرة beacon واحدة، فلاش الكاش الثلاثي القائم) · العضويات/EVO/الشركاء لم تُمس (كاناري).

### 2.7 قرار السعر العام (موثق بصدق)
المنظومة تخزن السعر API-served (payload + price_usd + price_updated_at) — صنف «سعر من API» المسموح ببند السعر §3.4-6. **لكن العرض العام يبقى «See price on Amazon»** (بوابة `AFFILIATE_STORE_SHOW_PUBLIC_PRICES` افتراضيًا OFF): سياسة أمازون تشترط أن يكون السعر المعروض طازجًا (≤ساعة) وجدوليتنا يومية/أسبوعية — القلب للعرض قرار مرحلة 4 من المالك مع ميزانية تحديث ≤ساعة. المخزن يخدم تحليلات الإدارة والتوافر.

2. فحص الرؤية العميق للصور (نموذج رؤية واحدًا-واحدًا كما بدفعة 528) يبقى مسار المحرر اليدوي؛ الأتمتة تعتمد بوابة المفردات + المضيف الموثوق + فئات منخفضة المخاطر — وكل منتج يفشل الحرّاس يُرفض ويُسجل.
3. عرض السعر العام معطل بقرار موثق (§2.7) حتى أمر مرحلة 4.
