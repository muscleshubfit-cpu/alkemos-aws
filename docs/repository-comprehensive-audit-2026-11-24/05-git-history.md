# 05 — سجل Git: الأعمال الملغاة والمتراجع عنها والمتوقفة والمكررة

> المنهجية: مسح رسائل كل الكوميتات على main (`git log --grep` بالعربية والإنجليزية لأنماط الإلغاء/التراجع)، فحص `git fsck --unreachable`، جرد الوسوم، ومطابقة النتائج مع التوثيق الحاكم. المرجع main `500ed1f2` عند 2026-11-24T21:00Z.

---

## 1. سلامة المخزن

- **`git fsck --unreachable`:** لا كوميتات غير قابلة للوصول — **لا عمل يتيم** بدأ وضاع خارج أي فرع.
- **لا stash** (استنساخ نظيف — والـ stash محلي بطبيعته ولا يظهر عن بُعد).
- **الوسوم:** اثنان أرشيفيان فقط (`archive/patch-1-uploads-20260819` · `backup/clean-2026-08-25`) — لا إصدارات معلنة (نشر مستمر من main).
- **تاريخ مُرحَّل:** يبدأ 2026-08-02 (Initial commit) — المستودع الحالي أُنشئ 2026-10-09 وورث التاريخ الكامل من المستودع السابق للانتقال (موثق) — لذا تحمل بعض رسائل الكوميتات القديمة أرقام PRs المستودع السابق (#5/#7).

## 5. التوصية

1. **لا يوجد عمل يحتاج إنقاذًا من سجل Git** — لا يتيم ولا معلق بلا فرع.
2. الفروع السبعة (5 مدمجة + 2 مكررة) مرشحة للحذف بأمر مالك مستقل (`02-branches.md` §4) — قرار تنظيفي بحت.
3. عند تنفيذ إصلاح فحص 0102 (U-1)، يُرجّح الخيار البنيوي (بصمة pg_proc) لأنه يحسم أيضًا الشك النظري الباقي حول أجسام الدوال على الإنتاج بقراءة واحدة.
