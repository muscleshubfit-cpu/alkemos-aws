# 08 — القائمة الموحدة بالأعمال المتبقية (غير مكررة)

> **المنهجية:** دمج كل المصادر (Issues · Branches · PRs · Code · Documentation) في بنود ذرّية غير مكررة — البند الواحد يجمع كل مصادره وأدلته. التصنيف: **قابل للتنفيذ الآن** (بأمر مالك أو آليًا) · **نافذة زمنية** (مؤجل بموعده ولا يحتاج فعلًا) · **قرار مالك مؤجل** (موثق بشرط فتحه — ليس فجوة) · **نظافة توثيقية** (مكتشف هذا التدقيق).
> **الأولويات:** P0 = يسبب ضررًا تشغيليًا مستمرًا أو يحجب مراقبة حقيقية · P1 = عمل حقيقي معلق قابل للفعل الآن أو بانتظار قرار مؤجل انقضى شرطه · P2 = تنظيف/بنود مؤجلة موثقة بأوامرها.
