## §1. الحكم في ثلاث جمل

1. **شرط إعادة التدقيق الإلزامية (أمر 2026-09-30) مُغلق بهذه الوثيقة:** حالة المستودع عند رأس main مطابقة حرفيًا لقيد التأجيل — سطح GSC لم يتغير منذ 2026-09-30 (سير عمل الاختبار dispatch-only + السر فقط، **صفر** جامع/تخزين/قرّاء/سير عمل مجدول/أسطح أدمن — مثبت بمسح قابل لإعادة التشغيل).
2. **الاتصال حي ومُعاد التحقق من المالك نفسه داخل النافذة نفسها:** 23 تشغيلة يدوية لسير عمل الاختبار (2026-10-10 → 2026-11-10) منها **16 تشغيلة داخل نافذة إعادة التدقيق: 13 ناجحة + 3 ملغاة** (31-10 · 03-11 · 05-11 ×2 · 10-11 ×12 منها 9 ناجحة و3 ملغاة بإعادة إطلاق) — آخر تشغيلة ناجحة 2026-11-10، أي قبل يوم ونصف من هذا التدقيق — **فلم تعد هناك حاجة لأي تشغيلة جديدة لإثبات الحياة**.
3. **قدرات حساب الخدمة القائم موثقة كاملةً:** Search Analytics مثبت حيًا، وURL Inspection API **ضمن النطاق القائم نفسه** (`webmasters.readonly` مؤهل — الحصة 2,000/يوم لكل موقع تكفي لوظيفة مثل A1 بأضعاف) لكنه قراءة-فقط (لا «طلب فهرسة» عبر API إطلاقًا) — **وكل تنفيذ فوق هذه القدرات يظل محظورًا داخل النافذة ويُفتح بأمر مالك من 2026-11-30**.

## §4. قدرات API الموثقة (القناة ج — `api-capabilities.md` بالخام)

| القدرة | الحالة لحساب الخدمة القائم (`webmasters.readonly`) |
|---|---|
| **Search Analytics (`searchAnalytics.query`)** | **مثبتة حيًا** (هي ما يشغّله سير العمل: نافذة 28 يومًا، `dataState=final`، 3 استعلامات/خاصية) — الحصص: 1,200/دقيقة لكل موقع · 30M/يوم لكل مشروع |
| **URL Inspection (`urlInspection.index.inspect`)** | **مؤهلة بلا أي تغيير نطاق** — التوثيق الرسمي يقبل `webmasters` أو **`webmasters.readonly`** · الحصة لكل موقع: **2,000/يوم · 600/دقيقة** (25 فحصًا للـA1 ≪ الحصة) — **قراءة-فقط**: لا «طلب فهرسة» عبر API إطلاقًا (واجهة GSC البشرية حصرًا — متسق مع قيد «لا طلبات فهرسة» القائم) |

| **طلب الفهرسة (Request indexing)** | غير موجود كقدرة API إطلاقًا — يظل فعلاً بشريًا بيد المالك حصرًا |

## §5. ما تفتحه هذه الوثيقة وما تظل تقيده (لا قرار يُغيَّر)

**تُغلق:** شرط «إعادة تدقيق إلزامية قبل أي تنفيذ GSC» (أمر 2026-09-30) — **مُستوفى وموثق** — فمن إغلاق النافذة (2026-11-30 فصاعدًا) يستطيع المالك، متى شاء وبأمره الذي يسمّي النطاق، تنفيذ الاندماج الدائم (جامع/تخزين/قرّاء/سير عمل مجدول/أسطح أدمن) أو أي بناء فوق القدرات الموثقة أعلاه.

**يظل مقيدًا حتى بأمر المالك (قوانين قائمة لا تُرفع):**
1. **حتى 2026-11-29:** لا أي تنفيذ GSC داخل النافذة (قيد أمر 2026-09-30 النصي) — بما فيه أتمتة URL Inspection للـ25 تجارية (A1) رغم أهليتها الموثقة — أي أن A1 تظل فعل المالك اليدوي (10 دقائق بواجهة GSC) حتى إغلاق النافذة، ثم تصبح قابلة للأتمتة بأمر.
2. **مبدأ المالك الملزم يظل قائمًا** بعد النافذة أيضًا: GSC لا يحدد مواضيع المحتوى الجديد — الاكتشاف بالبحث الخارجي الحي، وGSC دليل بعد النشر.
3. **لا طلبات فهرسة جماعية** ولا تغيير Validation (قيد الخطة القائم — التقرير 15 §5-ج) — URL Inspection لأي غرض يظل قراءة-فقط.

**الخيار الجاهز للقرار (من هذه الوثيقة، بأمر المالك وحده):** استمرار النهج اليدوي القائم (أثبت عمله: التصديران اليدويان شغّلا كل تحليلات الخطة؛ كلفته دقائق مالك متفرقة) — أو الاندماج الدائم من 2026-11-30 (القرار كما وثّقه أمر التأجيل نفسه).

- **صفر استدعاء GSC API** من هذه الجلسة — الدليل الطازج (تشغيلات المالك داخل النافذة) جُلب من صفحة Actions العامة قراءة-فقط.

- **لم تُطلق تشغيلة جديدة** لسير عمل الاختبار (لا حاجة — المالك أطلق 13 ناجحة داخل النافذة [من 16 تشغيلة] آخرها 10-11؛ ولو أُريد تحديث إضافي فهو فعل مالك بثوانٍ لأن السير dispatch-only).
- **لا قرار اندماج** صدر من هذه الوثيقة — القرار يظل للمالك، وكل ما هنا يجهّزه بالدليل.
