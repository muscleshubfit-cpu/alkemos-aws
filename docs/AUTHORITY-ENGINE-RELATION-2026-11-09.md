## 1) ماهية المحرك وعلاقته بموقع Alkemos

**Alkemos Authority Growth Engine** منظومة برمجية آلية مستقلة (Python + SQLite، تعمل على GitHub Actions مجانًا) مهمتها الوحيدة: **بناء السلطة الخارجية (Backlinks التحريرية) لموقع alkemos.com** بالطرق البيضاء حصرًا.

**سبب وجوده:** تدقيق انهيار SEO (الموثق في سلسلة `docs/seo-indexing-audit-2026-11-11/18-final-closure-report.md` وتقارير GSC اللاحقة) أثبت بالقياس أن الأساس التقني للموقع مكتمل وسليم (فهرسة/خرائط/hreflang/سكيما 100%)، وأن عنق الزجاجة هو **تقييم Google للجودة والسلطة**: نطاق عمره أسابيع قليلة، نطاقات محيلة شبه معدومة (5-20)، و31 انطباعًا/28 يومًا. المحرك يعالج هذا العنق تحديدًا — لا يعمل على تقنية الموقع إطلاقًا.

**العلاقة بالموقع (قراءة + إعادة استخدام مزود بريد، لا شيء أكثر):**

| اتجاه العلاقة | التفصيل |
|---|---|
| ما يقرأه المحرك من الموقع | أصوله العامة فقط: الأدوات الثمانية، مكتبة التمارين، قاعدة الأطعمة، المدونة — جُردت وتُحقق من حيويتها HTTP 200 في `assets/linkable_assets.yaml` بالمحرك |
| ما يعيد استخدامه من بنية الموقع | **مزود البريد نفسه**: Brevo Transactional REST API — نفس مزود مسار `/api/send-email` في هذا المستودع، بنفس نداء API حرفيًا ونفس منطق `validateEmailStrict` المنقول برمجيًا من `src/lib/email-validation.ts` |
| ما لا يفعله أبدًا | لا يعدّل كود هذا المستودع أو قاعدة بيانات Supabase أو بيئة الإنتاج أو إعداداته — عزل معماري كامل بمستودعين منفصلين |

## 2) أهداف المشروع واستراتيجيته

**الهدف:** روابط تحريرية (يقرر طرف ثالث وضعها بنفسه) من مواقع لياقة/تغذية موثوقة، تُقاس بـ: نطاقات محيلة جديدة، استمرارية الروابط (≥80%)، ونسبة dofollow — **لا بعدد الرسائل المرسلة**.

**الاستراتيجية (الدورة اليومية الآلية — مرتان يوميًا 05:00 و17:00 UTC):**

```
اكتشاف الفرص (بحث + ويكيبيديا + HN + إشارات العلامة)
→ تحليل جودة كل نطاق (عمر/صلة/ثقة) وتصنيف A-D — فقط A/B يتأهل
→ مطابقة كل فرصة مع أصل Alkemos محدد (أداة/قاعدة/منهجية)
→ تواصل عبر القنوات السبع (أدناه) بحدود آمنة ملزمة برمجيًا
→ مراقبة دورية للروابط + تقارير تفصل النتائج الفعلية عن المحاكاة
```

**القنوات السبع وحالتها الفعلية (2026-11-09):**

| # | القناة | الحالة | المتطلب الناقص |
|---|---|---|---|
| 1 | broken_links — اكتشاف روابط ميتة وعرض بديل | ✅ تعمل | — |
| 2 | email_brevo — بريد عبر نظام الموقع نفسه | ✅ تعمل فعليًا | — |
| 3 | contact_forms — نماذج تواصل المواقع بلا حسابات | ✅ تعمل فعليًا | — |
| 4 | curated_lists — مساهمات PR في قوائم awesome | ✅ تعمل فعليًا | — |
| 5 | devto_publish — نشر بـ canonical_url | 💤 نائمة | مفتاح API (لا يُطلب الآن) |
| 6 | hashnode — نشر أصلي عبر GraphQL | 💤 نائمة | Token + Publication ID |
| 7 | zenodo — فهرس أصول بـ DOI | 💤 نائمة | Token |

القنوات النائمة **مؤجلة بقرار موثق حتى توفر بياناتها** — لا تفترض أي حساب غير موجود ولا تعطل عمل القنوات المتاحة.

## 6) ضوابط الأمان والاستقلال عن الإنتاج

1. **عزل المستودعات:** المحرك لا يملك أي صلاحية على هذا المستودع أو بيئة الإنتاج؛ علاقته بالموقع قراءة أصوله العامة + إعادة استخدام مزود بريد Alkemos (Brevo) كما هو.
2. **لا مشاركة قاعدة بيانات:** قاعدة المحرك SQLite مستقلة تمامًا (`engine.db` داخل مستودعه) — لا اتصال بـ Supabase أو أي نظام للموقع.
3. **الأسرار:** مفاتيح المحرك (Brevo/PAT) أسرار GitHub في مستودعه الخاص — لا تظهر في أي كود أو تقرير؛ وفحص آلي يمنع رفعها (اختبار CI + سكربت محلي).
4. **حدود إرسال ملزمة برمجيًا:** 8 إرسالات فعلية/يوم (تُحتسب كلها بما فيها المرتدة) · 45 يومًا تهدئة لكل نطاق مشتركة بين القنوات · متابعة واحدة · قائمة استبعاد دائمة للعناوين المرتدة · DNC دائم لمن يطلب.
5. **خصوصية بيانات التواصل:** مستودع المحرك خاص، ولا نسخة عامة من لوحته أو تقاريره منذ 2026-11-09 (التقرير الأمني الكامل بالأدلة في `docs/SECURITY.md` بالمحرك).
6. **سلوك أخلاقي مبرمج:** احترام robots.txt وسياسات الناشرين، تخصيص حقيقي إلزامي (لا رسائل عامة)، لا شراء روابط، لا منصات تخالف شروطها.
