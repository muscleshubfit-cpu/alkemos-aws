# 05 — المخاطر والتكاليف والتراخيص (المرحلة 535 — 2026-11-28)

## §1 — تحليل التراخيص التفصيلي (فصل الكود عن البيانات — القيد السادس)

### 1.1 رخصة الكود (MIT)
- مستودع المصدر مرخص **MIT** (ملف `LICENSE` به) — تسمح بالاستخدام والتعديل والاستخدام التجاري والتوزيع بشرط إبقاء إشعار الترخيص لأي كود منقول نصًا.
- **القرار الموصى به:** إعادة كتابة الكود بمعايير Alkemos (وليس النقل الحرفي) — الاستثناءات المقترحة: مخططات Zod ومنطق dedup (تُنقل بتكييف مع تعليق مصدر + إبقاء إشعار MIT بأسفل الملفات المنقولة نصًا).
- **الحد الصريح:** MIT لا يغطي البيانات إطلاقًا — الكتالوع مرخص ODbL مستقلًا عن الكود.

### 1.2 ترخيص الكتالوج المجمّع (ODbL-1.0) — التحليل الحاسم
- الكتالوج يجمع مصادر ODbL (OFF ‏125,551 + OpenNutrition + الحزم المنسّقة) فيصبح **قاعدة بيانات مشتقة خاضعة لODbL-1.0** (إعلان صريح بملف بيان المصدر `catalog-manifest.json`).
- **ما يفرضه ODbL عند توزيع القاعدة (Convey):** (1) الإسناد الكامل للمصادر (2) المشاركة بالمثل — القاعدة المشتقة تُوزع بنفس ODbL.
- **ما لا يفرضه:** الاستخدام الداخلي وتقديم نتائج بحث/واجهة عبر الموقع (ليس توزيعًا للقاعدة نفسها) — الإسناد يظل ممارسة صحيحة استباقية.
- **القرار الموصى به — خيار الفصل:** جدول `food_catalog` منفصل يحمل صفوف المصدر حرفيًا (بلا دمج مع المكتبة الخاصة داخل نفس الجدول) — فالمكتبة الخاصة (8,162) تبقى ملكًا تجاريًا خالصًا والكتالوج المفتوح جدول ODbL مستقل بالإسناد الموثق. **الدمج داخل جدول واحد كان سيُخضع القاعدة كلها للمشاركة بالمثل عند أي توزيع مستقبلي.** الدمج المنطقي (البحث الموحد) يتم بطبقة الاستعلام لا بطبمة التخزين — وهذا جوهر توصية D-2(أ).

### 1.3 جدول التزامات المصادر الفردية (الطبقة الأساسية)
| المصدر | الترخيص | الالتزام عند الاستخدام |
|---|---|---|
| USDA FoodData Central | **CC0 1.0 / عام** | لا التزام قانوني (إسناد مستحسن ك ممارسة) |
| Health Canada CNF | **OGL-Canada 2.0** | إسناد صريح («Contains information licensed under the Open Government Licence – Canada») |
| Open Food Facts | **ODbL-1.0** | إسناد + المشاركة بالمثل عند توزيع القاعدة المشتقة |
| حزم منسّقة (المصدر) | ODbL/CC0 | حسب كل صف |

### 1.4 الإسناد العام (بوابة D-4)
- صفحة عامة `/data-credits` (أو قسم بالفوتر/الخصوصية): إسناد USDA/CNF/OFF + روابط تراخيصهم — نص بسيط بلغتي الموقع.
- إشعار داخلي: تعليق بالميجريشن + ملف `LICENSES-DATA.md` بالمجلد الحاكم.

### 1.5 المصادر الموسعة (F3-هـ — اختياري)
- **CC BY 4.0** (FoodRepo · AUSNUT · Japan MEXT · Germany BLS · Denmark Frida · Sweden Livsmedelsverket · India INDB): إسناد صريح + إشعار الترخيص.
- **Licence Ouverte 2.0** (France Ciqual): إسناد.
- **CC0** (Netherlands NEVO): لا التزام.
- **عام/أكاديمي مفتوح** (MenuStat · TBCA/TACO): يتحقق وقتها.
- كل مصدر يُضاف بقرار مالك مستقل بعد مراجعة ترخيصه.

### 1.6 سياسة المصدرين التجاريين
- المصدر لا يجمع APIs تجارية بحزمه (سياسة صريحة بـ`DATA_LICENSES.md`) — وAlkemos يعتمد OFF حيًا بالفعل — **قرار: عدم تبنّي FatSecret/Edamam/Nutritionix إطلاقًا** (تكلفة اشتراك + شروط خدمة مقيدة).

### 1.7 الحزمة المصرية (F3-ج)
- تُؤلَّف بملكيتنا **CC0** — من مصادر: `nutrient_reference` القائم (تحليل موثق بملكية المنصة) + تحقق مستقل من عبوات مصرية (الإلهام من OFF بلا نسخ صفوف — النقل منها يجعل الصفوف ODbL) + USDA للأغذية المكافئة (CC0).

## §3 — التكاليف التقديرية

### 3.1 التخزين والبنية
| البند | التقدير | ملاحظة |
|---|---|---|
| جدول `food_catalog` (130k صف) | ~65-100MB مع الفهارس | ضمن خطة Supabase الحالية (يتحقق وقت التنفيذ) |
| `food_logs` (نمو عضوي) | ~1KB/صف | ضئيل بالسنة الأولى (آلاف الصفوف شهريًا) |
| دلو صور الوجبات | ~200-400KB/صورة مضغوطة | سياسة الاحتفاظ تحسم (حذف بعد المعالجة ممكن — R4) |
| فهارس trigram | ~30-50MB | محسوبة ضمن البند الأول |

### 3.2 تكلفة AI (مسح الصورة — F2-ج)
| السيناريو الشهري | التقدير | ملاحظة |
|---|---|---|
| ≤100 مسح | ضمن الطبقة المجانية غالبًا | مزود رؤية مجاني الطبقة بالسلسلة (حدود معدل يومية) |
| ~1,000 مسح | ~$1-10 | حسب المزود/الموديل — يُقاس فعليًا بفريم تجريبي محدود قبل الفتح العام |
| ~10,000 مسح | ~$10-100 | يتطلب قرار تسعير/حصص مدروسًا (ربما حصرها بالباقات المدفوعة) |
> التقديرات استرشادية — القياس الفعلي بفريم تجريبي هو الحكم (قانون عدم الاختراع — §12.8).

## §4 — الالتزامات المستمرة بعد التشغيل
1. تحديث الكتالوج دوريًا (إعادة تشغيل خط البناء بCI — توصية فصلية) مع فحص العدد والجودة.
2. مراقبة p95 البحث ضمن سجل الأداء القائم.
3. مراجعة صفحة الإسناد عند أي تغيير بالمصادر.
4. مراقبة استهلاك حصة المسح شهريًا (لوحة الأدمن القائمة).
