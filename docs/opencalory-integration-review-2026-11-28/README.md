## القيود الثمانية الملزمة (من أمر المالك — تحكم كل تنفيذ لاحق)
1. Alkemos هو النظام الهدف الوحيد.
2. استبعاد كامل للقدرات دون اتصال: PWA Offline وIndexedDB وOPFS وكل معمارية مرتبطة بها.
3. ممنوع إنشاء تطبيق موازٍ أو قاعدة بيانات موازية أو نظام مستخدمين موازٍ — كل تبنٍّ يركب Supabase والمصادقة وRLS وأسطح Alkemos القائمة حصرًا.
4. لا تُنسخ أي ميزة قائمة قبل فحصها وتحديد فرصة تحسينها (موثق بالوثيقتين 02 و03).
5. ممنوع أي إشارة للمصدر في واجهة أو محتوى Alkemos.
6. تراخيص الكود والبيانات تُراجع كلٌّ على حدة — لا يُفترض أن MIT يغطي قاعدة البيانات (التحليل الكامل بالوثيقة 05).
7. لا يُعدَّل الإنتاج ولا قاعدته ولا إعدادات نشره في هذه المرحلة.
8. لا يبدأ أي تنفيذ أو ترحيل بيانات قبل اكتمال التقرير والخطة (مكتملان هنا) وموافقة المالك.
