### 2.4 هل الصفحات الداخلية في فهرس Google؟ (فصل الظهور عن الفهرسة)

**المقيس:**
1. استعلامات بحث خارجية (أداة بحث تُعيد نتائج من فهرس Google) أعادت صفحات داخلية محددة بألقابها ومقتطفاتها: صفحات تمارين EN (`/exercises/all-fours-quad-stretch`، `/exercises/press-sit-up`، `/exercises/spider-crawl`…) وAR (`/ar/exercises/exercise-ball-crunch`، `رفع الرجلين`) وأطعمة (`شاي أخضر`، `/foods/…`) ومقالات مدونة ومراكز (`/ar/exercises`، `/ar/equipment/machine`) — **[مُثبت: الصفحات حاضرة في الفهرس]**.
2. GSC (المصدر الرسمي) يُظهر ~50+ صفحة داخلية تحقق ظهورات في نافذة 28 يومًا بمراكز متفاوتة (2-100) — أي أنها مفهرسة وتُعرض فعلًا لكن بترتيب ضعيف للإنجليزية وترتيب جيد لذيل عربي.

**الاستنتاج الحاكم [استنتاج متسق]:** سؤال «لماذا لا تظهر الصفحات الداخلية في Google» إجابته المُقاسة **ليست «غير مفهرسة» بل:**
- **(أ) معظم الظهور المتبقي يذهب لاستعلامات العلامة والذيل الطويل العربي** بينما رؤوس الاستعلامات الإنجليزية (calorie calculator, bmi…) تحتكرها سلطات عريقة — الحاسبات الخمس الأعلى ظهورًا تاريخيًا كانت بمراكز 78-85 (بيانات نافذة ما قبل الانهيار، تدقيق 2026-10-19 §3.2).
- **(ب) سقف الفهرسة الموقعي منخفض** بسبب سلطة خارجية شبه معدومة (جرد P1-9: ‏5-20 نطاقًا محيلًا) — Google كان يعرف ~2,300 URL ورفض ~1,949 منها صراحة قبل الانهيار (تقرير Coverage ‏2026-10-12: crawled-not-indexed ‏1,068 · discovered-not-indexed ‏881).
- **(ج) أثر ثقة الإخراج الجماعي 04-08/10** (سبب Vercel الموثق بتدقيق الانهيار §1): خفض أولوية إعادة الزحف لدومين فتيّ — **إعادة الفهرسة الواسعة تحتاج أسابيع من الزحف التراكمي أو تدخل يدوي (URL Inspection) أو روابط خارجية**.

### 2.5 حدود قياس الفهرسة [متعذر — موثق]

- **عدد الصفحات المفهرسة فعليًا لا يُقاس من الجلسة**: نطاق `webmasters.readonly` لا يقدم URL Inspection عبر API إطلاقًا، وتقارير Page Indexing ليست في API — القناة الوحيدة: واجهة GSC بيد المالك (وثّق تدقيق 2026-10-19 §1.3 القيد نفسه).
- آخر تصدير Coverage مملوك للمستودع بتاريخ بيانات 2026-10-12 (قبل 19 يومًا) — **قديم نسبيًا ولا يُعتمد لوصف اليوم**.
- **التمييز الملزم (طلب المالك):** بيانات الظهور (Impressions) أعلاه ≠ الفهرسة؛ وطلبات الفحص/السماح بالفهرسة (إن نفذها المالك لاحقًا) ليست دليل فهرسة ناجحة — الدليل الوحيد: ظهور الصفحة في تقرير الأداء أو URL Inspection يظهر «URL is on Google».

- **الحكم [مُثبت]:** التكامل عبر هذا السر **غير منفذ** — لا سير ولا كود يرسل له؛ وجود السر وحده ليس دليلًا على عمل أي تكامل (نص طلب المالك نفسه). قيمته الغالبة: مفتاح Bing WMT API للإرسال (URL/Content Submission API) — قناة تتطلب **موقعًا متحققًا في Bing Webmaster Tools** أولًا (§8.3).

**الخلاصة:** لا يوجد دليل خارجي واحد على ملكية مثبتة في Bing WMT، وتدقيق 2026-10-18 وثّق «Bing: صفر صفحات مفهرسة» حينها وأوصى (بند 4) بـ«إرساء Bing Webmaster Tools (تحقق ملكية DNS)» — **لا مؤشر على تنفيذه منذ ذلك الحين**. الحالة الفعلية داخل BWT (إن وُجد حساب) تحتاج تأكيد المالك.

### 8.4 فهرسة Bing الحالية [متعذر القياس الموثوق — موثق]

- استعلام `site:alkemos.com` من هذه البيئة عبر Bing HTML: صفحة JS بلا نتائج قابلة للتحليل؛ عبر **Bing RSS: أعاد نتائج لا صلة إطلاقًا** (المشغل يُتجاهل — نفس القيد الموثق بتدقيق 2026-10-18 §6.2)؛ DuckDuckGo محجوب من الشبكة (HTTP 000).
- الخط الزمني الموثق بالمستودع: **~80,100 صفحة مفهرسة بـBing (2026-09-08 — خطة SEO-GEO §1) → صفر (2026-10-18 — تدقيق الانهيار P-1) → غير معروف اليوم**. IndexNow bootstrap (18-10) دفع 2,197/2,197 مقبولة — بلا دليل فهرسة تالٍ.
- قياس موثوق يتطلب واجهة BWT (Site Scan/URL Inspection بـBing) — **إجراء مالك** (دليل خطوات بالخطة §9).

### 8.5 اختبار التكامل العملي الآمن — ما نُفذ وما تعذر

- **نُفذ (بنجاح):** اختبار التكامل الفعلي القائم الوحيد — قناة IndexNow — عبر قراءة سجل تشغيله اليوم (دفع حي 5/5 مقبولة HTTP 200) + التحقق من مفتاح الملكية الحي. لم يُطلق dispatch إضافي لأن تشغيل اليوم المجدول أحدث من أي dispatch ممكن وكان كافيًا كدليل.
- **تعذّر (بسبب بنيوي موثق):** اختبار «Bing API» عبر `BING_WEB_MASTER` نفسه — لأن **لا مستهلك له أصلًا** (§8.2)، وقيمته غير قابلة للقراءة من GitHub بحكم التصميم، واختباره يتطلب إنشاء كود/سير جديد — **ممنوع بقيود هذه الجلسة («لا تعديلات على الكود»)**. عُوّض عنه بإثبات الوجود (الاسم/التاريخ) + إثبات انعدام الاستهلاك (grep) + تصميم التوصيل المقترح بالخطة (P1-4) جاهزًا للتنفيذ بأمر مالك مستقل.
