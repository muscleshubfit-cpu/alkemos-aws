## 1. الفكرة (النص المنقول من README)

الريبو مش معتمد على النوايا الحسنة — معتمد على **بوابات**.
مع كل push وكل pull request، GitHub Actions بتعيد اشتقاق الحقيقة من الكود نفسه، وبتفشل بصوت عالي على أي كذبة: مرآة schema انزاحت، وثيقة عدت، معرّف متقاعد رجع يظهر، أو ميجريشن هتكسر الداتابيز. البوابة الواقفة بتمنع الدمج — على runners بتاعة جيت هاب نفسها، مستقلة تمامًا عن أي جهاز محلي أو جلسة AI.

**كل بوابة تحت اتولدت من حادثة إنتاج حقيقية، وبعدين اتحولت لكود دائم:**

| البوابة | بتشتق / بتلقط إيه | الحادثة اللي بنتها |
|---|---|---|
| **Schema-drift audit** — `scripts/migration_audit.py` | بيفكك كل ميجريشن، ويقارن الـschema الناتج بمرآة `types.ts` الميدانية + baseline مقبول موثق؛ أي جدول/عمود فانتوم أو ناقص **جديد** = فشل الدفع (وضع `--ci`) | أعمدة فانتوم في المرآة وقّفت خط ميجريشنز الإنتاج الحي (`42703`) وكسرت مسارات أعضاء بصمت |
| **Registry parity** — `scripts/docs_parity.py` | بيعيد عدّ الميجريشنز على القرص كل تشغيل — ترويسة سجل `INDEX.md` لازم تتساوى مع حقيقة الفايل سيستم | الوثائق اتجمدت على مرحلة قديمة والمنتج فضل يشتغل؛ الانجراف عدّ شهور من غير حد يشوفه |
| **Knowledge operating system** — `scripts/docs_audit.py` | سلامة `STATE.md` (≤100 سطر، أقسامها الإلزامية، والكوميت المسجل فيه لازم يكون سلفًا لـHEAD — الحالة عمرها ما بتشاور لقدام) · تساوي المرحلة عبر STATE/PROGRESS/QA · **صفر** عدادات متغيرة في README/DEVELOPER_GUIDE (قانون المصدر الواحد للأرقام — الأرقام بيتها الكود) · ممنوع تكرار أرقام الأقسام في `AGENTS.md` · وثائق حية نحيفة بمؤشرات أرشيف · **(المرحلة 215 — فحوص الحقيقة H/I/J):** ترتيب worklog جديد-فوق (نافذة الـ12 العلوية بتاريخ/طور تنازلي + أحدث مدخل في القمة + ذيل مجمّد بثابت مشتق من النافذة ذاتها — المرحلة 234: لا مدخل أسفل النافذة أحدث من أقدم مدخل مؤرخ داخلها؛ الثابت اليدوي أُحيف) · ترويسات «Last updated/آخر تحديث» للوثائق الخمس المحكومة مقابل git (فوريًا فقط من 2026-09-16 — الانحراف الأقدم ملك المرحلة 217) · تجميد الأرشيف الحرفي (PROGRESS/QA_CHECKLIST صفر كوميتات من 2026-09-16) · **(المرحلة 234 — فحص K لخطة الترحيل Phase 2):** ترويسة «## Task ID:» مشوهة = فشل فوري (صنف F-02) · **(المرحلة 237 — الخطة Phase 5):** هيكل §12.5.1 الكامل لكل مدخل حي = فشل فوري عند النقص (التطبيع تم بالدوران) + سقف بايتات STATE صلب 32,000 (بدل تحذير 48KB) · **(المرحلة 274 — DOC-REMEDIATION):** تسعة فحوص مضادة للانجراف — أنماط أرقام موسعة للدليل (اختبارات/جداول اعتماديات/قيم ألوان) · Task IDs مؤرخة إلزاميًا (سد فجوة الإلحق بأسفل worklog) · بريد الديمو موحد مع بذر auth.ts · تواريخ سجل docs/README مقابل git لكل صف + وجود كل مسار · تغطية CI_GATES لكل ملف workflow · متطلب Node لا يقل عن engines · أي ذكر «OpenRouter + Groq» يستلزم NVIDIA · مسارات backtick بالوثائق الحاكمة يجب أن توجد · أوامر run الموثقة يجب أن تكون scripts حقيقية | حقائق مكتوبة في أماكن متعددة عدت بشكل مختلف — وملف القانون نفسه مرة شال §3.6 مكرر — والتدقيق العميق 2026-09-16 ضبط ترتيب worklog مكسور وترويسات كاذبة وأرشيف معدّل بعد التجميد والبوابة عمياء عنها كلها |
| **Anti-regression guard** — `scripts/check-stale-refs.sh` + `scripts/check-ui-wiring.sh` | فشل سريع على أي معرّف متقاعد رجع (روايتس متشالة، كومبوننتس ميتة، أسماء خطوط أنابيب قديمة) وعلى توصيل UI مكسور: أهداف fetch ميتة، أنواع jobs من غير معالج، معالجات من غير jobs، إنهاءات runner غير صادقة | روايتس AI متقاعدة فضلت شغالة بالتوازي مع الطابور الجديد — صنف «edits vanish» اللي المالك شافه بعينه |
| **Supabase Preview** | كل دفعة بتتطبق على داتابيز preview حقيقية عبر أكمال Supabase GitHub — ميجريشن واحدة فاشلة بتوقف الخط قبل ما توصل للإنتاج | اتعملت إثبات لايف: عمود واحد وحش جمّد دفتر الميجريشنز وسدّد صمت كل الميجريشنز اللي وراه |

**فوق البوابات، كل دفعة بتشغّل البطارية القياسية:** TypeScript `strict` · ESLint · مجموعة Vitest كاملة — كل البوابات zero-dependency وبتشرح الفشل inline (`::error::`) وبتخلص في ثواني.

**ليه ده مهم:** الوثائق مش ممكن تكذب، والمرآة مش ممكن تنزاح، والكود المتقاعد مش ممكن يرجع من الموت، وحالة المشروع الحالية دايمًا موجودة في [`STATE.md`](../STATE.md) — مدخل مُدار بقراءة 30 ثانية. وعلشان البوابات ساكنة جوه الريبو نفسه (`.github/workflows/` + `scripts/`)، بتسافر تلقائيًا مع أي نسخة نظيفة أو rebrand في المستقبل. ده اللي يخلي الريبو آمن للتطوير بمساعدة الوكلاء: أي جلسة، بشرية أو AI، تقدر تثق في الباب الأمامي من غير حفريات أثرية.

## 4. قوانين مكملة من AGENTS.md تخص صحة البوابات

- **قانون مكافحة الانحدار (§8):** إيقاف أي شيء (route/component/script/step) = `git rm` + كنس المستدعين + تصحيح التعليقات في **نفس الكوميت**، صفر ملفات شواهد قبور، ثم `check-stale-refs.sh` يطلع 0 قبل الدفع؛ والحارس يعيد الفحص على كل دفعة. عند «سلوك رجع للوراء» افتح `/api/build-info` وقارن `commitShort` بأحدث SHA على main — عدم تطابق = تأخر/فشل deploy، ممنوع تصحيح كود ضد deploy قديم.
- **لون التشغيل الصادق (§8):** أي runner داخل `scripts/*-runner/*` لازم يحمل مسار exit غير صفرى صريح (مفروض بـCI) — تشغيل أخضر معنى الحقيقي الوحيد: `done=N failedPermanent=0`.
- **مناعة الجدولة (SCHEDULE HEALTH LAW):** جدول جيت هاب ممكن يسجّل خروج صامت لكل workflows المجدولة — أي بلاغ «المدونة واقفة» بيبدأ بجنائيات الجدولة (`GET /actions/runs?event=schedule`) مش بإعادة قراءة كود الأنابيب؛ والعلاج: تمكين كل workflow + كوميت يلمس ملفاتها لإعادة التسجيل؛ والظهر المستقل: `/api/cron/dispatch-pipelines` (فشل مغلق، CRON_SECRET) بيكمّل حصة اليوم الناقصة (مقال واحد لكل لغة — Phase 119) يوميًا 23:40 UTC (بعد فتحتَي اليوم لكل لغة وبعد فترة السماح 90 دقيقة — المرحلة 171: الفتحة تُعد متوقعة بعد ساعتها بـ90 دقيقة، والتغطية = أقصى (تشغيلات غير فاشلة، مقالات منشورة فعليًا اليوم)، والقانون نفسه يُفرض في P5: صف آلي لا ينشر مقالًا ثانيًا بنفس اليوم — صفوف الكوتش معفاة).
- **حادثة Phase 110 الموثقة (2026-09-03):** worker الـAI قعد أحمر على «Install dependencies» بانهيار npm 10 arborist (`Cannot read properties of null (reading 'edgesOut')`) ضد metadata الريجستري بتاريخ اليوم — الريبو بلا lockfile فالتثبيت بيحل فريش كل مرة، وnpm 11.17 حل نفس الشجرة سليمة محليًا → خطوة «Bump npm (npm install -g npm@11)» اتضافت قبل التثبيت في كل الـworkflows المكشوفة الأربعة. الدرس: فشل «Install dependencies» في CI يُشخّص كطبقة بنية تحتية أولًا قبل الشك في كوميت الكود. **الحل الجذري (Phase 141 / 2026-09-07):** طبقة الحل المؤقت ده (Bump npm + حل فريش بلا lockfile) اتبدلت بـ`bun install --frozen-lockfile` في الـworkflows الأربعة — نفس قفل الإنتاج (`bun.lock`)، فانجراف الشجرة مستحيل أصلاً وحادثة من الفئة دي مقفولة.
