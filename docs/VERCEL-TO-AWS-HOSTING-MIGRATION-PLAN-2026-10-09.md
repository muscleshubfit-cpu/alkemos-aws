## 4. الفجوات المقيسة خارج Vercel — والعلاج (كلاهما في `deploy/Caddyfile`)

**الفجوة 1 — هيدرز الأمان:** `vercel.json` يضخ على حافة Vercel سبعة هيدرز أمان (`X-Content-Type-Options` · `X-Frame-Options` · `Referrer-Policy` · `HSTS` · `Permissions-Policy` · `CSP` · `CSP-Report-Only`) — **غابت كلها عن أصل AWS المقيس** لأن `next.config.ts` لم يكررها. العلاج (بدون أي تعديل كود): **نسخها الحرفي في `Caddyfile`** (الملحق ب) — مقارنة بايت-ببايت قبل القطع (مرحلة 4). لاحظ أن CSP-Report-Only يسمح بـ`va.vercel-scripts.com` و`static.cloudflareinsights.com` — يبقى كما هو (تماثل التراجع).

**الفجوة 2 — Cache-Control لعائلة الصور العامة (اكتشاف تنفيذ المرحلة 1، 2026-10-09):** قاعدة `/images/(.*) → public, max-age=86400` تعيش في `vercel.json` **فقط** — `next.config.ts` headers() يغطي `/images/brand/*` و`/images/exercises/*` و`/sw.js` وHTML العام، لكن **ليس** بقية شجرة `public/images/` (ملفات الجذر + `hero/` + `og/` + `programs/` + `authors/` + `categories/`). **مقيس على أصل مجرد:** هذه الملفات تصدر بـ`Cache-Control: public, max-age=0` بينما حافة Vercel تعطيها 86400. العلاج: قواعد مكافئة **حرفية القيم** في `deploy/Caddyfile` بترتيب صحيح (العامة أولًا ثم الخاصة لتغلب عليها — نفس دلالات تخصيص vercel.json، مقيس). **قانون `defer` (مقيس حيًا على Caddy 2.8):** بدون `defer` تُنفَّذ عملية `header` قبل اندماج استجابة الأصل فيظهر **هيدران Cache-Control مزدوجان** على السلك؛ مع `defer` تُطبَّق وقت كتابة الاستجابة **باستبدال** — وهي دلالة حافة Vercel بالضبط، فكل قواعد الكاش أدناه مؤجلة. قاعدة `/_next/image` **لا تُنسخ عمدًا** (المسار ميت 410 بحرس الحصة). هيدرز `Cache-Control` للـHTML **لا تُلمس** — مصدرها الصحيح `next.config.ts` headers() وهي تعمل مقيسًا من الأصل.

## 7. لماذا Node+PM2 مباشرة وليس Docker (بلا افتراض أن Docker «ضروري»)

1. **الكود نفسه لا يطلب حاوية:** لا `Dockerfile` ولا `docker-compose` بالمستودع، والتطبيق عديم الحالة (صفر كتابات FS — مقيس) — الحاوية لا تحل أي مشكلة قائمة.
2. **الدليل العملي حاضر:** بناء+تشغيل+استجابة كاملة على Node عادي في <3 دقائق (§2) — بما فيها مسار الـedge الوحيد.
3. **الكلفة التشغيلية لـDocker هنا:** خط إضافي كامل (بناء صورة → دفع لـregistry (ECR) → سحب على الخادم → إدارة إصدارات الصور) + مساحة قرص للصور + فقدان بساطة «عدّل ملفًا وأعد التشغيل» — مقابل صفر منفعة لخادم تطبيق واحد.
4. **Docker يصبح منطقيًا مستقبلًا فقط عند:** تعدد خدمات على نفس الخادم، أو اشتراط توحيد بيئات فريق متعدد، أو حاجة عزل صارم — لا شيء منها قائم.
5. **PM2 يغطي كل ما كانت ستغطيه الحاوية:** إعادة تشغيل عند الانهيار، cluster mode عند الحاجة، إدارة سجلات، تشغيل عند الإقلاع (`pm2 startup`).

## 10. HTTPS وCloudflare (بلا أي تغيير DNS الآن)

الوضع الحالي: DNS على Cloudflare (زون Free) ببروكسي أمامي وكاش HTML رسمي (قاعدة `alkemos cache rules` + RSC bypass — أربع قواعد حية موثقة). الخطة **لا تغير شيئًا في Cloudflare سوى عنوان الأصل** وقت القطع (سجل A/AAAA واحد). شهادة الأصل: **Caddy يجلب Let's Encrypt تلقائيًا** عبر HTTP-01 — يعمل خلف بروكسي CF طالما SSL mode = Full-strict (الحالي). البديل إن حدث تعارض: شهادة **Cloudflare Origin CA** (15 سنة، من لوحة CF، توضع في Caddy يدويًا). الحجب: ‏80/443 فقط، وSSH مقيد بعنوان المالك.

## ملحق ب: `deploy/Caddyfile` (**منشأ على الفرع** — الهيدرز حرفية من `vercel.json` + قواعد كاش الصور؛ يُراجع بايت-ببايت بمرحلة 4)

```caddyfile
alkemos.com {
        encode zstd gzip
        # 1) هيدرز الأمان السبعة — قيم حرفية من vercel.json (§4 الفجوة 1)
        header {
                defer
                X-Content-Type-Options "nosniff"
                X-Frame-Options "SAMEORIGIN"
                Referrer-Policy "strict-origin-when-cross-origin"
                Strict-Transport-Security "max-age=63072000; includeSubDomains; preload"

                Content-Security-Policy "frame-ancestors 'self'; base-uri 'self'; object-src 'none'; form-action 'self'"
                Content-Security-Policy-Report-Only "…حرفي من vercel.json…"
                -Server
        }

        header /images/* {
                defer
                Cache-Control "public, max-age=86400"
        }
        header /sw.js {
                defer
                Cache-Control "public, max-age=0, must-revalidate"
        }
        header /_next/static/* {
                defer
                Cache-Control "public, max-age=31536000, immutable"
        }
        header /images/brand/* {
                defer
                Cache-Control "public, max-age=300, stale-while-revalidate=604800"
        }
        header /images/exercises/* {
                defer
                Cache-Control "public, max-age=31536000, immutable"
        }
        # 3) بث SSE بلا تخزين مؤقت + مهل مفتوحة تكفي مسارات الـ300ث
        reverse_proxy 127.0.0.1:3000 {
                flush_interval -1
        }
}
www.alkemos.com {
        redir https://alkemos.com{uri} permanent
}
```
