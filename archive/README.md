## أين أجد ماذا؟

- **الحالة الحالية للمشروع** → `STATE.md` (الجذر) — لا هنا أبدًا.
- **ماذا نُفذ في مهمة قديمة وما كان قرارها؟** → ابحث بمعرف المهمة في `archive/WORKLOG_ARCHIVE.md` (كل مدخل يحمل خلاصته وكوميته).
- **التفاصيل التنفيذية الكاملة لمهمة قديمة** → تاريخ git (`git log --all --oneline` ثم `git show <sha>`) — النص الحرفي الكامل للأرشيفات المضغوطة محفوظ هناك قبل 2026-11-25.
- **حالة مرحلة تاريخية أو دليل QA قديم** → `archive/PROGRESS_ARCHIVE.md` / `archive/QA_CHECKLIST_ARCHIVE.md` (خلاصات).
- **تقرير تدقيق/خطة منفذة قديم** → `docs/archive/` (الفهرس: `docs/archive/README.md`).
- **قوانين التوليد وسبب وجودها** → `archive/PROMPT-LAW-HISTORY.md` + AGENTS.md §8.
